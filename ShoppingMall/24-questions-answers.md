# 24 - 问大家（UGC 问答）

## 1. 需求背景与目标

- **背景**：详情页评价解决「买过的人怎么说」，问大家解决「还没买想知道的事」（尺码准不准/耐不耐用），补充决策信息。
- **目标**：问大家渗透率（详情页访问→提问/浏览）≥10%；问题 48h 内被回答率 ≥70%。
- **非目标**：不做官方客服自动应答（39 客服职责）；不做悬赏问答（P2）。

## 2. 用户故事

- 作为买家，我想要向买过的人提问（尺码/质量/兼容性），以便获得买家视角的真实答案。
- 作为买过的买家，我想要被邀请回答相关问题，以便我的经验帮助别人。
- 作为平台，我想要过滤广告与违禁问答，以便内容可信。

## 3. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 24-3-1 | 提问：详情页入口，问题 ≤50 字，绑定 SPU；同 SPU 问题去重（相似问题合并展示） | P1 |
| 24-3-2 | 邀请回答：优先推送给「已购买该 SPU」且高信用买家（41 信用分），每问题最多邀请 20 人；App 推送/站内信（40） | P1 |
| 24-3-3 | 回答：≤300 字 + 可附图；回答者展示「已购买」标记 | P1 |
| 24-3-4 | 展示：详情页模块显示 Top3 回答（按有用排序）+ 「查看全部」 | P1 |
| 24-3-5 | 有用投票：买家对回答点赞；排序按有用数 | P1 |
| 24-3-6 | 商家参与：商家可回答（带「商家」标记，显式区分买家回答）；商家不可删除买家回答 | P1 |
| 24-3-7 | 内容治理：广告/导流/违禁词机审（42）；可举报（43），核实删除 | P1 |
| 24-3-8 | 问题流排序：详情页内按热度（浏览+回答数） | P1 |

## 4. 流程

```
买家提问 → 相似问题合并校验 → 发布（机审）
 → 邀请已购用户 → 用户回答（48h 内响应最优）
 → 内容排序展示 → 持续投票修正排序
 → 低质问题（无回答 7 天）沉底，推送二次邀请
```

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 无人回答 | 7 天无回答 → 推送详情页降权展示；引导买家改问客服（39 入口提示） |
| 恶意刷「有用」 | 41 行为识别，票数清洗 |
| 回答含竞品导流 | 42 词库拦截 |
| 提问者删除问题 | 已有回答保留（社区资产），问题标记「已删除」 |
| 商家自导自演问答（小号提问自答） | 41 关联账号识别，命中则内容隐藏 + 43 处罚 |

## 6. 数据与埋点

- 事件：`qa_ask(spu_id)` / `qa_answer` / `qa_like` / `qa_module_view`
- 指标：提问量/回答率/回答时长中位数、商家回答占比（异常监控）、举报率、模块渗透率。

## 7. 依赖与接口

- 依赖：08 SPU（绑定）、16 购买关系（邀请对象）、41/42 治理、40 邀请触达。
- 提供：`SPU 问答聚合查询`（09 详情页消费）。

## 8. 开放问题

- 是否允许未购买用户回答（经验型回答，需「未购买」标记）？（转 51）
- 热门问题是否沉淀为详情页 FAQ 常驻展示？（转 51）
