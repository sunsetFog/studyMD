# 44 - 广告投放

## 1. 需求背景与目标

- **背景**：广告（竞价）是平台主要营收之一；核心是「商家 ROI 可衡量 + 买家体验不劣化」。
- **目标**：广告主 30 天留存 ≥60%；广告 CTR 不低于自然 CTR 的 80%（质量底线）。
- **非目标**：不做站外投放（ADX 对接 P2）；不做品牌广告排期售卖（P2）。

## 2. 用户故事

- 作为商家，我想要对关键词出价获取靠前曝光，以便低成本获客。
- 作为商家，我想要清晰看到花费/点击/转化/ROI，以便调整投放。
- 作为买家，我想要广告相关性高且明确标识，以便不被低质广告打扰。

## 3. 产品需求

### 3.1 广告产品类型（P0/P1）

| 类型 | 展示位置 | 计费 | 优先级 |
|---|---|---|---|
| 搜索竞价 | 搜索结果固定坑位（11：第 3/9/16 位） | CPC（点击计费） | P0 |
| 商品展示推广 | 推荐信息流（12 坑位） | CPC | P1 |
| 活动会场广告 | 会场坑位（28） | CPM/坑位费 | P2 |

### 3.2 商家投放台（P0）

| 条目 | 需求 |
|---|---|
| 44-3-1 | 计划创建：选商品（在售 SKU 08）→ 选关键词（含系统推荐词与热度）→ 出价（关键词维度，底价/封顶）→ 日预算 |
| 44-3-2 | 创意：默认用商品主图+标题（08 素材），可选自定义创意（审核 42） |
| 44-3-3 | 出价与排名：综合分 = 出价 × 质量分（CTR/CVR 历史 + 类目相关性）；GSP 计费（下一名价格+0.01） |
| 44-3-4 | 预算控制：日预算花完自动暂停（平滑消耗）；预算告警（40） |
| 44-3-5 | 报表：展现/点击/花费/转化/ROI，按关键词与商品维度；建议调价提示 | P0 |
| 44-3-6 | 负关键词：排除无效流量词 | P1 |
| 44-3-7 | 自动出价（智能投放）：设定目标 ROI，系统自动调价 | P2 |

### 3.3 买家侧规则（P0）

- 广告位必须带「广告」标识（合规）。
- 广告坑位数量上限：搜索页 ≤3/屏；信息流占比 ≤10%（12 联动）。
- 低质量广告拦截：预估 CTR < 自然均值的 50% → 不予展示（42 质量审核 + 44 质量分兜底）。

## 4. 流程

```
商家创建计划 → 审核（商品合规 42 + 创意）→ 生效
 → 用户搜索 → 竞价排序（GSP）→ 广告展示（标识）
 → 点击计费（防刷扣费：41 无效点击过滤，退返）→ 转化归因
 → 报表 T+1 → 商家调价
```

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 恶意点击消耗 | 无效点击识别（41 同 IP/设备/行为特征）→ 费用退返 + 报告 |
| 广告商品中途下架/违规 | 计划自动暂停（08 状态联动） |
| 预算超扣（高并发扣费竞态） | 预算原子扣减（49），超扣部分自动退返 |
| 转化归因争议 | 点击 7 天归因窗口，规则公示 |
| 商家对扣费有异议 | 工单（39→财务 35） |

## 6. 数据与埋点

- 事件：`ad_impress(slot, plan_id)` / `ad_click` / `ad_charge(amount)` / `ad_convert(order_no)`
- 指标：各坑位 CTR/CVR、平均 CPC、广告 GMV 占比、质量分分布、无效点击率、商家 ROI 分布与流失率。

## 7. 依赖与接口

- 依赖：11/12/28 流量坑位、08 商品状态、41 反作弊、42 审核、35 费用结算（广告费先扣后结或预充值，规则待定）。
- 提供：`竞价服务（请求级）`、`扣费/退返`、`投放报表`。
