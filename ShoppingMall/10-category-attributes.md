# 10 - 类目与属性体系

## 1. 需求背景与目标

- **背景**：类目是商品组织的骨架——发布表单、搜索筛选、推荐、佣金率都挂在类目上。
- **目标**：类目树变更生效延迟 ≤ 1 分钟；商品类目错挂率 ≤ 3%。
- **非目标**：本篇不含类目前台运营页（专题楼层见 28），只管结构与规则。

## 2. 数据模型

### 2.1 类目树（P0）

```
类目树：L1（一级）→ L2 → L3 → L4（叶子，可挂商品）
示例：服饰 → 男装 → T恤 → 短袖T恤（叶子）
```

| 字段 | 规则 |
|---|---|
| `category_id` | 全局唯一，不可复用（已删类目 id 永久封存） |
| 层级 | 最多 4 级；仅叶子类目可发布商品 |
| 佣金率 | 类目级配置（35 结算依据），L2 层继承可覆盖 |
| 状态 | 启用/禁用/迁移中；禁用类目禁止新发布，存量商品要求迁移 |
| 审核属性 | 该类目下商品是否需资质（如食品经营许可），资质要求见 32/42 |

### 2.2 属性体系（P0）

| 概念 | 定义 | 示例 |
|---|---|---|
| 属性 | 类目挂载的结构化字段 | 「T恤」挂：材质、袖长、风格、适用季节 |
| 属性值 | 属性可选值（枚举）或自由文本 | 材质：棉/麻/聚酯纤维 |
| 销售属性 | 参与 SKU 组合的属性 | 颜色、尺码 |
| 关键属性 | 影响搜索筛选与结构化展示 | 材质、袖长 |
| 显示属性 | 仅详情参数表展示 | 产地 |

**规则**：
1. 属性挂在**类目**上，商品继承；类目属性变更后存量商品不强制回填，编辑时才要求补全。
2. 销售属性由平台枚举管控（防止商家自造「均码 XL」导致筛选失效）；非枚举类目（如二手）例外，P2。
3. 每个叶子类目：关键属性 3-8 个、销售属性 ≤2 个。

### 2.3 前后台类目分离（P1）

- **后台类目**（本篇）：运营管理用，稳定严谨。
- **前台类目**（导航楼层，如「女装」「数码」）：运营可配置，映射多个后台类目；App 首页类目入口用前台类目（47）。

## 3. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 10-3-1 | 类目管理后台：树的增删改、层级限制、启用禁用、迁移 | P0 |
| 10-3-2 | 属性管理：属性增删、枚举值维护、类目挂载 | P0 |
| 10-3-3 | 类目迁移工具：批量把 A 类目商品迁到 B，映射表可预览、可回滚 | P1 |
| 10-3-4 | 前后台类目映射配置 | P1 |
| 10-3-5 | 类目变更全站生效（发布表单/筛选/佣金）延迟 ≤1 分钟 | P0 |

## 4. 流程：类目变更生效

```
运营后台变更类目 → 审批（运营主管）→ 生成变更事件 → 消息广播
 → 发布表单/搜索索引/佣金配置缓存失效重建 → 全站生效
 → 涉及存量商品：生成迁移任务列表，运营分批处理
```

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 删除有商品的类目 | 禁止；必须先迁移或清空 |
| 迁移失败部分商品 | 生成失败清单，支持重试；迁移任务幂等（49） |
| 枚举值删除（已有商品在用） | 软删除：新商品不可选，存量保留 |
| 类目循环引用 | 保存时校验，禁止 |
| 佣金率调整 | 只影响调整后的新结算周期，历史账单不追溯（35 确认） |

## 6. 数据与埋点

- 指标：各叶子类目商品量、错挂类目纠正量、类目筛选使用率（搜索侧联动 11）。

## 7. 依赖与接口

- 提供：`类目树查询`、`类目属性查询`（发布表单与详情页动态渲染依据）、`类目佣金率查询`（35）。
- 依赖：审核后台（42，资质类目标记）。
