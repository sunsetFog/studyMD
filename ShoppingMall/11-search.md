# 11 - 搜索

## 1. 需求背景与目标

- **背景**：搜索是电商最大流量入口，搜索质量直接决定转化率。
- **目标**：首结果相关率 ≥90%（人工评估）；搜索 UV 占比 ≥40%；零结果率 ≤2%。
- **非目标**：不做语音搜索（P2）；不做站外搜索广告托管（44 管广告排序层）。

## 2. 用户故事

- 作为买家，我想要用自然语言搜到想要的商品，以便快速决策。
- 作为买家，我想要品牌/价格/规格等筛选条件，以便收窄结果。
- 作为商家，我希望合规商品能被正确召回，且不因关键词缺失而失去曝光。

## 3. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 11-3-1 | 基础召回：标题、类目、关键属性、品牌、店铺名多字段索引 | P0 |
| 11-3-2 | 搜索排序：相关性为主，结合销量/评分/转化率/纠纷率的综合排序模型（可配置权重） | P0 |
| 11-3-3 | 筛选器：按类目动态渲染筛选面（10 关键属性驱动）+ 价格区间 + 发货地 + 是否包邮 + 评分门槛 | P0 |
| 11-3-4 | 搜索建议（sug）：输入联想、热词、纠错提示 | P0 |
| 11-3-5 | 拼写纠错与同义词：默认自动纠错（顶部提示「已为您展示 xx 的结果」）；同义词库（如卫衣=连帽衫） | P0 |
| 11-3-6 | 零结果优化：放宽召回 + 类目推荐 + 热门商品兜底 | P0 |
| 11-3-7 | 排序选项：综合/销量/价格升降/评分（价格排序必须可用，防比价流失） | P0 |
| 11-3-8 | 历史搜索与热门搜索（个人历史 ≤20 条，可删） | P1 |
| 11-3-9 | 图搜（拍照/识图搜索） | P2 |
| 11-3-10 | 广告位：结果页第 3/9/16 位竞价坑位，标记「广告」（44），不影响自然排序统计 | P1 |

### 3.1 排序因子与权重（后台可调）

| 因子 | 说明 | 默认权重参考 |
|---|---|---|
| 文本相关性 | 标题命中 > 属性命中 > 类目命中 | 40% |
| 交易热度 | 近 7/30 天销量（去刷单量，41 降权） | 20% |
| 质量分 | 评分（36）、退货率、纠纷率反向 | 20% |
| 时效性 | 新品加权期 14 天 | 10% |
| 服务分 | 发货时效、客服响应 | 10% |

**违规降权**：命中 43 章处罚（降权/屏蔽）的商品在召回层直接过滤或沉底。

## 4. 流程

```
输入 query → sug 联想 → 召回（多字段+同义词扩展）
 → 粗排（相关性）→ 精排（综合因子）→ 业务规则（去重/打散同店 ≤3 条/违规过滤）
 → 广告坑位插入（44）→ 返回（含筛选聚合数据）
```

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 召回服务超时 | 降级返回缓存热门结果（46），顶部提示「网络波动」 |
| query 含违禁词 | 拦截并零结果（42 词库） |
| query 为空/纯符号 | 引导热门搜索 |
| 筛选条件无结果 | 逐步放宽提示：「已为你放宽 xx 条件」 |
| 刷单商品混入热销 | 41 疑似刷单销量不计入排序因子 |

## 6. 数据与埋点

- 事件：`search_input(query)` / `search_submit(query)` / `sug_click` / `result_click(rank, sku_id)` / `filter_use` / `page_scroll_depth`
- 指标：CTR（首屏与全量）、零结果率、纠错命中率、筛选使用分布、query→下单转化率、无点击 query TopN（产品优化输入）。

## 7. 依赖与接口

- 依赖：商品索引（08 变更事件驱动索引更新 ≤1 分钟）、类目（10 筛选面）、44 广告、41 风控。
- 提供：`搜索结果查询`、`搜索词分析`（运营与选品输入）。
