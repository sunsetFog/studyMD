# 12 - 推荐系统产品需求

## 1. 需求背景与目标

- **背景**：推荐承担「逛」的流量分发（首页信息流/详情页相似/加购后凑单），目标是提升非搜索路径 GMV 占比。
- **目标**：推荐渠道 GMV 占比 ≥20%；首页信息流 CTR ≥6%。
- **非目标**：本篇为产品需求与体验规则，不定义算法实现细节；不覆盖直播流量（29）。

## 2. 用户故事

- 作为买家，我希望首页信息流推荐我感兴趣的商品，以便「逛」中 discovery。
- 作为买家，我希望推荐不重复打扰（同款不反复出现、看过的可隐藏）。
- 作为商家，我希望新品与新店有冷启动流量池，以便公平获得初始曝光。

## 3. 推荐场景清单

| 场景 | 位置 | 策略要点 | 优先级 |
|---|---|---|---|
| 首页信息流 | 首页第二屏起瀑布流 | 个性化为主 + 新品冷启动配额 | P1 |
| 相似商品 | 详情页底部（09） | 同类目/同价格带/同属性为主 | P0 |
| 凑单推荐 | 购物车凑单入口（13） | 满减门槛差额 ±30% 价位带 | P1 |
| 购后推荐 | 订单完成页/确认收货页 | 关联互补品（买了手机→手机壳） | P1 |
| 失效替代 | 购物车失效区（13） | 同款或同型在售 SKU | P0 |
| 会员专属 | 个人中心（48） | 会员价商品（06） | P2 |

## 4. 功能需求（体验规则）

| 条目 | 需求 | 优先级 |
|---|---|---|
| 12-4-1 | 个性化：基于行为（浏览/加购/购买/搜索）与画像（类目偏好/价格带）实时重排 | P1 |
| 12-4-2 | 冷启动：新用户按热销榜 + 大众分布兜底；新商品/新店 14 天冷启动流量配额池（保底曝光，每周对商家可见数据） | P1 |
| 12-4-3 | 多样性打散：同店连续 ≤2 条；同 SPU 去重；类目多样性约束 | P1 |
| 12-4-4 | 负反馈：「不感兴趣」按钮（长按或角标），同类目 7 天降权；「看过了」折叠 | P1 |
| 12-4-5 | 合规过滤：违规/降权商品（43）不可出现在推荐；秒杀商品只在其时段推（26） | P0 |
| 12-4-6 | 感知公平：新品流量配额与爆款挤占的平衡由运营侧「流量分配看板」（45）监控 | P1 |
| 12-4-7 | 停止推荐切换：关闭个性化开关后仅按热销/编辑精选（合规隐私要求） | P1 |

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 推荐服务超时 | 降级为热销榜静态位（46），不白屏 |
| 新用户无行为 | 兜底热销 + 注册时兴趣选择（04 引导） |
| 推荐到失效商品 | 请求时二次校验可售状态（08 状态），失效实时过滤 |
| 价格带漂移（用户点了一次奢侈品被狂推） | 单次行为不进入长期画像；行为权重衰减（产品规则） |

## 6. 数据与埋点

- 事件：`feed_impress(trace_id, item_list)` / `feed_click(rank)` / `dislike_click(reason)` / `similar_impress`
- 指标：各场景 CTR/CVR、GMV 归因、多样性指标（同店占比/类目熵）、负反馈率、冷启动商品曝光→首销周期。

## 7. 依赖与接口

- 依赖：行为埋点（45）、商品可售状态（08）、44 广告（信息流广告坑位占用）。
- 提供：`推荐接口（按场景）`、`负反馈上报`。

## 8. 开放问题

- 冷启动流量配额是否向高评分店铺倾斜？（转 51）
- 首页信息流广告密度上限（建议 ≤10%）？（转 51，与 44 联动）
