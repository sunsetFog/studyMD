# 25 - 优惠券

## 1. 需求背景与目标

- **背景**：优惠券是最通用的营销工具；核心难点是生命周期管理（发放→领取→核销→退回）与防资损。
- **目标**：券核销率 ≥25%；资损（超发/套现）0 容忍；发放链路 P99 <200ms。
- **非目标**：不做实物卡券/礼品卡（P2）；不做裂变红包（41 风险高，P2 再议）。

## 2. 用户故事

- 作为买家，我想要领取店铺券/平台券并在结算时抵扣，以便省钱。
- 作为商家，我想要创建店铺券并控制预算，以便可控获客。
- 作为运营，我想要管理平台券的发放计划与监控核销，以便营销 ROI 可度量。

## 3. 数据模型

### 3.1 券模板（campaign）

| 字段 | 规则 |
|---|---|
| 类型 | 满减券 / 折扣券 / 无门槛券 / 运费券 |
| 适用范围 | 平台券（全平台）/ 店铺券（单店）/ 类目券（P1） |
| 门槛与面额 | 满减：满 X 减 Y；折扣券：X 折，最高优惠封顶 |
| 数量与预算 | 发放总量、单用户限领数（默认 1） |
| 有效期 | 绝对时间 / 领取后 N 天 |
| 叠加规则 | 引用 19 章叠加互斥配置 |
| 预算 | 商家券受店铺营销预算限制（35 费用承担：商家承担或平台补贴） |

### 3.2 用户券（instance）

状态机：`未领取（库存中） → 已领取 → 已使用 / 已过期 / 已退还 → 已过期`

## 4. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 25-4-1 | 领券：详情页/店铺页/领券中心（48）一键领取；库存原子扣减（18 同款机制防超发） | P0 |
| 25-4-2 | 我的券包：可用/已用/已过期分区；临期券（3 天）置顶提醒（40） | P0 |
| 25-4-3 | 结算使用：默认最优（19），券与门槛实时校验（商品变更后失效重算） | P0 |
| 25-4-4 | 核销：支付成功才真核销；下单未支付仅预占（18 锁定），关单释放 | P0 |
| 25-4-5 | 退回：订单全额退款且券在有效期内 → 返还；已过期返还无效（14/17 提示） | P0 |
| 25-4-6 | 定向发放：新客券（04 注册钩子）、会员券（06 等级权益）、活动批量发放（28） | P1 |
| 25-4-7 | 防刷：同设备/同账号频次限制、高危账号禁止领券（41） | P0 |
| 25-4-8 | 核销对账：每日核销流水 vs 券消耗对账，差异告警 | P0 |

## 5. 流程

```
创建模板（商家/运营）→ 审批（预算校验）→ 上线 → 用户领取（原子减库存）
 → 结算选用（19 计算）→ 下单锁定 → 支付成功核销
 → 全额退款 → 有效期内返还 / 关单 → 释放
```

## 6. 异常与边界

| 场景 | 处理 |
|---|---|
| 领券并发超发 | 原子扣减，库存为 0 提示「已抢完」 |
| 券在结算中被其他人使用不存在（个人券独占） | 不存在共享问题；但活动券「限量池」领取时按库存处理 |
| 门槛临界商品退款后券已用 | 部分退款不返还券；门槛失效争议走 22 |
| 券叠加规则配置错误 | 19-4-5 资损护栏兜底 |
| 商家中途下线券 | 已领取的仍可用至有效期（用户权益优先） |

## 7. 数据与埋点

- 事件：`coupon_receive(template_id)` / `coupon_use(order_no)` / `coupon_expire`
- 指标：领取率/核销率/过期率、券带来的 GMV 归因（用券单 vs 无券单）、超发告警、各类型券 ROI。

## 8. 依赖与接口

- 依赖：19 算价、14 锁定核销时序、41 防刷、40 提醒。
- 提供：`可领券列表`、`用户券包`、`核销/返还接口`。
