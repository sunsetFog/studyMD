# 42 - 商品审核与合规

## 1. 需求背景与目标

- **背景**：商品/内容/资质审核是平台合规底线（广告法/产品质量/知识产权）；审核吞吐决定商家体验。
- **目标**：机审覆盖率 100%；人审时效 ≤24h（大促 ≤4h）；违规商品线上滞留 ≤2h。
- **非目标**：不做法务咨询（合规条款解释由法务）；本篇不含 UGC 问答细节（24 引用本篇能力）。

## 2. 审核对象与场景

| 对象 | 触发场景 | 优先级 |
|---|---|---|
| 商品 | 新发布/修改重新提交（08）、巡查抽检 | P0 |
| 商家资质 | 入驻（32）/资质到期更新 | P0 |
| 营销资产 | 券模板/活动报名（25/28） | P0 |
| 评价/问答/内容 | UGC 发布（23/24/30） | P0 |
| 直播 | 实时画面/语音（29） | P1 |

## 3. 审核流水线（P0）

```
提交 → 机审（自动）→ 通过：直接上架 / 不确定：进人审队列 / 违规：驳回
 → 人审：审核工作台（图片逐张/文本/资质证件）→ 通过/驳回（原因+修改指引）
 → 上架后巡查：抽样机审+举报触发 → 违规处置（43）
```

### 3.1 机审能力清单

| 能力 | 检测内容 | 应用 |
|---|---|---|
| 文本审核 | 违禁词（极限词/涉政涉黄/导流词）、标题党 | 08 标题/详情、23 评价、30 内容 |
| 图片审核 | 涉黄/暴恐、二维码水印（导流）、假证合成 | 08 主图/详情图 |
| 资质核验 | 证件 OCR + 真伪核验接口、有效期 | 32 |
| 品牌保护 | 商标白名单比对、侵权投诉库 | 08 品牌 |
| 类目错挂 | 文本-类目一致性模型 | 08/10 |

### 3.2 人审工作台（P0）

| 条目 | 需求 |
|---|---|
| 42-3-1 | 任务队列：按对象类型/风险等级分派；高危优先（资质造假疑似） |
| 42-3-2 | 审核界面：原图/缩放对比、历史审核记录、违规词高亮、快捷驳回理由（可编辑模板） |
| 42-3-3 | 审核一致性：同类案件标准答案库；抽检复核（质检员按 5% 抽审） |
| 42-3-4 | 审核效率：平均耗时统计、积压告警（46） |

## 4. 举报通道（P0）

- 举报入口：商品/内容/评价/问答均可举报（分类选择 + 证据上传）。
- 处理：举报进人审队列，12h 内响应；核实违规 → 43 处罚 + 通知举报人；恶意举报（41 识别）→ 举报人处罚。

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 机审误杀（误判违规） | 驳回原因明确可申诉（43），申诉走人审复核；误判样本回流优化 |
| 大促审核洪峰 | 预案：机审阈值放宽 + 人审加班排班 + 非紧急队列延迟（46） |
| 审核期间商品已在售（编辑场景） | 旧版本继续售卖至新版本审核通过（不中断经营） |
| 审核标准更新 | 标准文档版本化 + 审核员培训通知；规则库热更新（46） |
| 审核员权限滥用 | 操作留痕（03/32），数据导出审计 |

## 6. 数据与埋点

- 指标：机审通过率/人审分流率、人审时效、驳回原因 TopN（商家教育材料）、举报量与核实率、误判率（申诉翻案率）、审核一致性抽检合格率。

## 7. 依赖与接口

- 依赖：43 规则与处罚、41 黑名单、10 类目资质配置。
- 提供：`审核提交 API`（各发布链路）、`审核结果事件`（08/32 状态驱动）、`机审能力 API`（24/30 复用）。
