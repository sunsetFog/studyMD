# 47 - App 信息架构与导航

## 1. 需求背景与目标

- **背景**：App 信息架构决定用户心智（「想买去哪找」）；底部导航是最高频入口分配决策。
- **目标**：核心任务（搜索→详情→下单）≤3 步；首页 3 秒任务达成率 ≥90%。
- **非目标**：不做多主题皮肤（P2）；本篇覆盖 App + H5 共用结构。

## 2. 底部导航（5 Tab）

| Tab | 名称 | 内容 | 优先级 |
|---|---|---|---|
| 1 | 首页 | 运营楼层 + 商品瀑布流（推荐 12）+ 类目入口（10 前台类目） | P0 |
| 2 | 分类 | 前后台类目树导航（10）+ 分类推荐位 | P0 |
| 3 | 中间 Tab | 拍立淘/图搜（P2）或直播聚合（29，阶段可选） | P2 |
| 4 | 购物车 | 13 购物车（角标数量） | P0 |
| 5 | 我的 | 个人中心（48：订单/资产/工具） | P0 |

## 3. 首页结构（自上而下）

```
搜索栏（常驻吸顶：入口 11）
→ 金刚区（8-10 图标：领券中心/秒杀 26/拼团 27/直播 29/会员 06/新品…运营可配）
→ 运营楼层（28 会场楼层：大促 Banner/类目楼层）
→ 直播卡片流（29）
→ 商品瀑布流（12 推荐信息流，无限下滑）
```

楼层配置由运营后台管理（28-3-6），支持分时段/分人群投放（45 圈选）。

## 4. 全局页面清单（按域汇总）

## 5. 导航规则（P0）

| 规则 | 说明 |
|---|---|
| 返回栈 | 任意页面可达「我的」与首页（≤2 次返回）；详情页层级不超过 5 级 |
| 登录墙 | 浏览免登录；加购（游客态本地 13）/下单/支付/资产类强制登录 |
| 深链 | 商品/店铺/直播间/活动页支持深链跳转（分享 09-3-8、27 开团依赖） |
| 空态规范 | 每列表页有统一空态组件（图标+文案+行动按钮：去逛逛/搜索） |
| 加载规范 | 统一骨架屏；禁止白屏；失败可重试（46 降级） |

## 6. 异常与边界

| 场景 | 处理 |
|---|---|
| 深链商品已下架 | 落地失效态（09-3-6）+ 推荐替代 |
| 版本过低（新功能不支持） | 功能开关按版本灰度；强制升级仅限重大安全修复 |
| 楼层配置下发失败 | 缓存兜底显示上次配置 |
| 中间 Tab 空置期 | 双 Tab 中间位隐藏（4 Tab 布局），保留扩展性 |

## 7. 数据与埋点

- 事件：`tab_switch` / `floor_view/impress` / `kingkong_click(icon_id)`
- 指标：Tab 分布、楼层 CTR、金刚区点击分布（运营位效率）、路径深度分布（核心任务步数验证）。

## 8. 依赖与接口

- 依赖：28 楼层配置、12 推荐流、10 前台类目、40 公告 Banner。
- 提供：`首页楼层配置读取`、`全局导航路由表`（深链注册）。
