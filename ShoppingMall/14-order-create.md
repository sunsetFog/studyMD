# 14 - 下单与结算页

## 1. 需求背景与目标

- **背景**：结算页是从「想买」到「付钱」的最后一站，流失率最高的页面；同时是价格计算与拆单规则的集中执行点。
- **目标**：结算页→支付成功率 ≥85%；下单接口 P99 < 800ms（46）。
- **非目标**：不做下单后改价（商家改价 P2）；不做货到付款（P2）。

## 2. 用户故事

- 作为买家，我想要一页看清商品、优惠、运费与合计，以便放心付款。
- 作为买家，我想要选择/新增收货地址并看到预计送达时间，以便规划收货。
- 作为买家，我想要自动使用最优优惠组合，以便不操心凑单。

## 3. 结算页信息结构

| 区块 | 内容 | 优先级 |
|---|---|---|
| 收货地址 | 默认地址展示，可切换/新增（38）；无地址阻断提交 | P0 |
| 商品清单 | 按订单分组展示（拆单规则 4.2），SKU/数量/单价 | P0 |
| 优惠明细 | 可展开：各层优惠（店铺券/平台券/满减/积分）逐项列示 | P0 |
| 运费 | 按订单展示（37 运费模板计算） | P0 |
| 发票 | 电子普票抬头（P1）/专票（P2） | P1 |
| 备注 | 订单留言（≤200 字） | P0 |
| 支付方式 | 见《15》 | P0 |
| 合计与提交 | 明细金额 + 提交订单按钮 | P0 |

## 4. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 14-4-1 | 从购物车结算：仅提交勾选 SKU；从详情页「立即购买」：单品快捷下单（不进购物车） | P0 |
| 14-4-2 | 拆单规则：跨店铺必拆；同店铺按「发货仓/运费模板/活动类型」拆单（同一 SKU 不会被拆分） | P0 |
| 14-4-3 | 优惠计算：调《19 价格优惠引擎》，展示计算过程明细 | P0 |
| 14-4-4 | 价格保护：提交前校验价格与进入页面时差异 >0.1% 时，弹窗告知新价格需确认 | P0 |
| 14-4-5 | 下单限流校验：库存预占（18）、限购（41）、风控（41）三层前置校验 | P0 |
| 14-4-6 | 幂等提交：客户端生成下单幂等键，重复提交返回同一订单（49） | P0 |
| 14-4-7 | 支付超时 | P0 |
| 14-4-8 | 积分抵扣选择（06）与优惠券选择（25），默认最优组合 | P0 |
| 14-4-9 | 预售/拼团等特殊下单模式接入（27 的入口规则） | P1 |
| 14-4-10 | 下单页保留 15 分钟：超时返回购物车并释放预占库存 | P0 |

### 4.1 下单流程

```
结算页提交 → 参数校验（地址/库存/限购/风控）
 → 价格计算锁定快照（19：锁定本次金额，防支付期间变价）
 → 库存预占（18，15 分钟）
 → 生成订单（状态 CREATED）+ 拆单
 → 跳转收银台（15）
 → 支付成功 → 订单 PAID → 预占转实扣
 → 超时未支付 → 自动关单（16）→ 预占释放
```

### 4.2 拆单规则明细

| 条件 | 是否拆 |
|---|---|
| 跨店铺 | 必拆（独立订单、独立履约、独立售后） |
| 同店不同仓库 | 拆（物流单不同） |
| 同店不同运费模板 | 拆 |
| 普通商品 + 预售商品 | 拆（发货时效不同，16） |
| 同 SKU 多件 | 不拆 |

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 双击提交/网络重试 | 幂等键防重（49），返回已有订单 |
| 预占库存失败（并发抢购） | 返回「库存不足」，引导去相似商品；不产生订单 |
| 地址校验失败（不可达区域 38） | 阻断提交并提示 |
| 支付页放弃返回 | 订单保留至超时关单；返回结算页价格保护窗重开 |
| 优惠在支付前过期 | 已锁价快照不追溯（本单按快照成交），下单一律按新规则 |
| 大额未实名 | 触发 07 实名流程后继续（保留结算态 10 分钟） |

## 6. 数据与埋点

- 事件：`settle_view(items)` / `address_change` / `discount_expand` / `order_submit(success/fail, reason)` / `price_alert_show`
- 指标：下单成功率与失败原因分布、拆单率（订单数/购买 SKU 数）、平均优惠金额、价格保护弹窗率（异常信号）。

## 7. 依赖与接口

- 依赖：13（结算预校验）、18（预占）、19（算价）、25/28（优惠）、38（地址）、41（风控）、15（收银台）。
- 提供：`创建订单（幂等）`、`订单金额快照查询`（15/16/35 依据）。
