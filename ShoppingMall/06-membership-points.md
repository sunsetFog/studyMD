# 06 - 会员等级与积分体系

## 1. 需求背景与目标

- **背景**：提升复购与留存需要忠诚度体系；积分同时是营销资产与成本中心，必须强规则化。
- **目标**：会员用户月复购率高于非会员 15%+；积分兑付成本控制在 GMV 的 0.3% 以内。
- **非目标**：不做付费会员（88 会员类）——列为 P2 单独立项。

## 2. 用户故事

- 作为买家，我想要消费获得积分，以便下次抵扣省钱。
- 作为高价值买家，我想要更高等级与权益，以便获得专属优惠与服务。
- 作为运营，我想要灵活配置积分规则与等级权益，以便做成本可控的营销。

## 3. 功能需求

### 3.1 积分获取规则（P0，后台可配置）

| 行为 | 基础规则 | 限制 |
|---|---|---|
| 消费返积分 | 每 1 元消费 = 1 积分（按实付金额，不含运费） | 确认收货后 T+1 发放；退款按比例扣回 |
| 评价 | 首评 +5 / 晒图 +10 | 每订单限一次；审核通过后发放 |
| 签到 | 每日 +1，连续 7 天额外 +10 | 每日限一次 |
| 活动 | 运营配置 | 需活动预算管控（28） |

**积分上限**：单用户每月获取上限（防薅，默认 5000，可配）；作弊获取积分由 41 章风控冻结。

### 3.2 积分使用（P0）

- **抵现**：结算页可选，100 积分 = 1 元；单笔订单抵扣上限为实付的 30%（可配）。
- **兑换**：积分商城（P1）兑换券/实物；兑换后不可退。
- **有效期**：滚动 12 个月过期（月末清零当期获分），过期前 30/7/1 天推送提醒（40）。

### 3.3 会员等级（P1）

| 等级 | 升级条件（近 12 个月） | 核心权益 |
|---|---|---|
| 普通 | 注册即得 | — |
| 铜 | 消费 ≥500 元 | 生日券 |
| 银 | 消费 ≥2000 元 | 会员价商品、优先客服 |
| 金 | 消费 ≥8000 元 | 专属折扣、免费退货运费 |
| 黑卡 | 邀请制 | 专属客服、极速退款（20） |

- 等级每月 1 日重算（消费口径含退货扣减）；降级不清权益，只影响下期升级。
- 会员价与店铺折扣的叠加互斥规则参见《19 价格优惠引擎》。

## 4. 流程：积分发放与扣回

```
订单确认收货 → T+1 批任务结算积分 → 入账（流水：来源/订单号/数额/有效期）
 → 该订单发生退款 → 按退款比例扣减积分
   → 积分不足扣回：负数记账，后续获取优先冲抵，抵现不可用直至冲平
```

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 退款时积分已部分消费 | 进入负数账本，后续积分优先冲抵 |
| 并发使用积分（多端同时下单） | 结算页预占积分，见《14》幂等规则 |
| 积分兑换后订单退款 | 积分兑换环节不可逆，不回补 |
| 风控判定刷分 | 冻结积分 + 通知申诉；确认作弊则清零（43） |

## 6. 数据与埋点

- 事件：`points_earn` / `points_deduct` / `points_redeem` / `level_upgrade`
- 指标：积分发放量/兑付率/过期作废率、各等级用户占比与 ARPU、会员权益使用率。

## 7. 依赖与接口

- 依赖：订单中心（16，确认收货事件）、退款（20/21 扣回）、风控（41）。
- 提供：`积分余额查询`、`积分抵扣预占/确认/回滚` 给结算页（14）。
