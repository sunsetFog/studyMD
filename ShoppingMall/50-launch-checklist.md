# 50 - 上线检查清单（V1.0 MVP）

## 1. MVP 范围确认（对应 01 阶段规划）

**包含**：04 注册登录 / 08 商品发布 / 10 类目 / 11 搜索（基础版）/ 13 购物车 / 14 下单 / 15 支付 / 16 订单 / 18 库存 / 20 仅退款 / 32 入驻 / 34 发货 / 37 物流基础 / 42 审核 / 46 非功能达标。

**不包含（后续版本）**：推荐（12）、评价（23）、优惠券（25）、秒杀（26）、直播（29）、广告（44）等。

## 2. 功能验收清单

### 2.1 买家链路
- [ ] 注册登录全流程（含找回密码、异常登录提醒 05）
- [ ] 搜索→详情→加购→结算→支付→订单 全链路冒烟通过
- [ ] 游客态浏览/加购，登录合并（13）
- [ ] 下单拆单（跨店）、价格快照、幂等提交（14/49）
- [ ] 支付成功/超时关单/关单后支付竞态退款（15-4 竞态规则）
- [ ] 订单状态全流转与倒计时（16）
- [ ] 未发货取消 + 全额退款 + 资产回冲（17/18/25）
- [ ] 仅退款全流程 + 超时自动同意（20）

### 2.2 商家链路
- [ ] 入驻：资质提交→审核→保证金→开店（32）
- [ ] 商品发布：多规格 SKU/草稿/审核驳回修改/上下架（08）
- [ ] 打单发货：电子面单取号/批量发货/拦截回执（34/37）
- [ ] 待发货/售后处理工作台（33）

### 2.3 治理与支撑
- [ ] 商品机审+人审流水线（42）
- [ ] 风控接入点全部上线：注册/领券/下单/支付/退款（41）
- [ ] 消息通知：交易强通知 100% 必达（40）
- [ ] 客服机器人 + 人工接待（39 基础版）
- [ ] 对账任务：支付/库存/券三方日对账（49-5）

## 3. 非功能验收（46 全清单）

## 5. 上线节奏

| 阶段 | 内容 |
|---|---|
| 灰度 | 内部员工 → 5% 真实流量（重点监控支付成功率/客诉） |
| 放量 | 5%→50%→100%，每步 ≥2 天观察 |
| 应急预案 | 一键回滚版本 + 一键下线新功能开关（46） |
| 驻场 | 上线首周值班（产品+研发+运营），每日晨会复盘 |
