# 05 - 账号安全中心

## 1. 需求背景与目标

- **背景**：账号盗用会直接造成资金损失与纠纷（盗号下单、盗用退款）。需要一个集中展示与处置的安全中心。
- **目标**：盗用账号导致的资金损失投诉 ≤ 月均 5 例；风险登录 100% 可追溯。
- **非目标**：不覆盖支付渠道侧的风控（支付机构自有风控，15 章只做联动）。

## 2. 用户故事

- 作为用户，我想要看到我的登录设备列表并踢出陌生设备，以便掌控账号安全。
- 作为用户，我想要在异地登录时收到提醒，以便及时发现盗用。
- 作为被风控的用户，我想要清晰的申诉路径，以便恢复账号。

## 3. 功能需求

### 3.1 安全中心页面（P0）

| 模块 | 内容 |
|---|---|
| 安全等级 | 综合评分（0-100）：由密码强度/实名/绑定方式/最近风险行为加权 |
| 登录设备列表 | 设备名、最近登录时间地点、当前在线标记；支持「踢下线」 |
| 风险事件列表 | 异地登录、密码错误激增、敏感信息修改，含时间与处置结果 |
| 安全设置 | 改密码、绑定管理、登录验证方式开关 |

### 3.2 异常登录处置（P0）

| 风险级别 | 判定（由风控引擎 41 输出） | 处置 |
|---|---|---|
| 低 | 同城换设备 | 正常登录，记风险事件 |
| 中 | 跨省异地 + 新设备 | 登录成功但推送提醒 + 交易时二次验证（48h 内） |
| 高 | 爆破特征/黑名单设备/历史被盗号特征 | 拦截登录，通知原绑定手机号 |

### 3.3 敏感操作保护（P0）

- 敏感操作清单：改绑手机号、改密码、注销账号、改收款信息（商家）。
- 规则：需短信验证码二次确认；改绑手机号后 **24 小时内禁止提现/转账类操作**（防劫持账号转移资产）；操作后全端通知。

## 4. 流程：异常登录

```
登录请求 → 风控评分（41）→ 分级处置（3.2）
 → 若为异地新设备：登录成功 → App 推送+短信「您的账号在新设备登录…非本人可一键冻结」
 → 用户点击「冻结」：账号进入限制登录态，解冻需原手机验证码
```

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 原手机号已停用 | 走人工申诉通道（39 工单），需身份证明材料（07 实名） |
| 用户被误风控 | 申诉工单，风控专员 24h 内处理（43 申诉规则） |
| 设备列表满（>10 台） | 自动清退最旧非活跃设备并通知 |
| 冻结期间有进行中订单 | 订单不受影响，正常履约；但禁止新交易 |

## 6. 数据与埋点

- 事件：`security_page_view` / `device_kickoff` / `freeze_click` / `risk_login_notify`
- 指标：异常登录拦截量、冻结转化率、申诉量与申诉通过率。

## 7. 依赖与接口

- 依赖：风控引擎（41）、消息中心（40）、实名（07）。
- 提供：`账号风险等级查询` 给交易域（下单前校验）。
