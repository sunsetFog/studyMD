# 32 - 商家入驻

## 1. 需求背景与目标

- **背景**：商家入驻是平台供给的入口；资质审核决定平台合规底线（类目资质 42 联动）。
- **目标**：入驻审核时效 ≤2 个工作日；一次通过率 ≥70%；资质造假识别率（年检）≥95%。
- **非目标**：不做个人卖家免费入驻（统一企业/个体户资质，平台定位 B2C 倾向）。

## 2. 用户故事

- 作为企业商家，我想要在线提交资质并跟踪审核进度，以便尽快开店。
- 作为平台，我想要多维校验商家资质真实性，以便守住合规与消费者信任。

## 3. 入驻流程

```
注册商家账号（04 主账号）→ 选择店铺类型 → 填写资质材料 → 提交
 → 平台审核（资质真实性 + 类目授权）→ 通过 → 签署协议
 → 缴纳保证金（07 钱包/对公）→ 开店成功（店铺初始化 33）
```

### 3.1 店铺类型（P0）

| 类型 | 资质要求 | 保证金（参考，可配） |
|---|---|---|
| 旗舰店 | 品牌商标注册证（R/TM） | 类目基准 × 1 |
| 专卖店/专营店 | 品牌授权链（≤2 级） | 类目基准 |
| 个体店 | 个体工商户执照 | 类目基准 × 0.5 |
| 卖场型旗舰店 | 卖场资质 + 多品牌授权 | 类目基准 × 1.5 |

### 3.2 资质材料清单（P0）

| 材料 | 校验方式 |
|---|---|
| 营业执照 | OCR + 工商接口核验（统一社会信用代码真实性） |
| 法人身份证 | 二要素（07 同源） |
| 品牌资质 | 商标证/授权书（有效期校验；TM 标需 6 个月以上） |
| 类目特殊资质 | 食品经营许可/化妆品生产许可/3C 认证等（10 类目配置驱动） |

## 4. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 32-4-1 | 入驻申请表单：按店铺类型动态渲染（联动 10 类目资质要求） | P0 |
| 32-4-2 | 资质审核台：审核员工作台（42 复用），驳回需给具体原因与补件指引 | P0 |
| 32-4-3 | 保证金管理：金额按类目计算；在线支付（15）或对公凭证上传；可查询余额 | P0 |
| 32-4-4 | 入驻进度可视化：五节点时间轴（提交/初审/复审/协议/保证金） | P0 |
| 32-4-5 | 驳回后补件：材料级修改重新提交，已通过材料不重复提交 | P0 |
| 32-4-6 | 资质到期提醒：有效期前 60/30 天通知（40）；到期未更新 → 类目商品下架（43） | P0 |
| 32-4-7 | 保证金扣划：22 仲裁裁决/43 处罚从保证金划扣，低于基准 80% 需限期补足，否则限售 | P0 |
| 32-4-8 | 退出：商家主动关店——须结清订单售后（20/21 完结）+ 90 天无交易冷却期 → 退保证金（35 到账） | P0 |
| 32-4-9 | 多店铺：一个主体最多 5 店（品牌数校验） | P1 |

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 资质造假（工商核验不符/PS 证照） | 直接拒绝并列入黑名单（41），主账号关联主体禁止再入驻 |
| 保证金支付失败 | 保留申请态 7 天；超时作废可重新提交 |
| 类目资质补充（后续扩展类目） | 增量审核该类目，不影响已开类目 |
| 主体信息变更（换法人/名称） | 重新审核主体资质，期间店铺正常经营 |
| 关店时售后未完结 | 阻断退保证金；订单售后全部终态后进入冷却期 |

## 6. 数据与埋点

- 事件：`onboard_start/submit/audit_pass|reject/deposit_paid/store_created`
- 指标：入驻漏斗转化、审核时长、驳回原因 TopN、保证金余额（平台负债）、资质到期未更新数。

## 7. 依赖与接口

- 依赖：04 账号、10 类目资质配置、15 支付、07 钱包、42 审核台、40 通知、35 结算。
- 提供：`商家主体信息查询`（33/35/43 消费）、`保证金余额查询`（22 划扣）。
