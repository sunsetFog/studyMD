# 19 - 价格与优惠计算引擎

## 1. 需求背景与目标

- **背景**：优惠叠加规则是营销体验与资损控制的核心；计算口径不一致（详情页 vs 结算页）是投诉高发点。
- **目标**：算价一致性 100%（详情页/购物车/结算页同口径）；优惠资损率 ≤0.1%。
- **非目标**：不做动态定价/千人千价（合规风险，不做）。

## 2. 价格体系

| 价格概念 | 定义 | 来源 |
|---|---|---|
| SKU 售价 | 商家设置的销售价（展示主价） | 08 |
| 划线价 | 参考价（仅展示，禁止虚构，43 违规项） | 08 |
| 到手价 | 应用全部可叠加优惠后的最终价 | 本引擎 |
| 会员价 | 按会员等级折扣（06） | 06 配置 |

## 3. 优惠类型与叠加规则（核心）

### 3.1 优惠分层

| 层 | 类型 | 示例 |
|---|---|---|
| 商品级 | SKU 直降、限时价（26） | 单 SKU 内生效 |
| 店铺级 | 店铺券、满减、满折（25/28） | 同店内多 SKU 分摊 |
| 平台级 | 平台券、跨店满减（25/28） | 跨订单分摊 |
| 用户级 | 积分抵扣、会员价（06） | 与上述叠加 |

### 3.2 叠加/互斥规则（P0，后台可配）

| 组合 | 规则 |
|---|---|
| 商品级 × 商品级 | 互斥，取用户最优（默认） |
| 商品级 × 店铺级 × 平台级 | 可叠加 |
| 平台券 × 跨店满减 | 默认可叠加（大促标配），运营可关 |
| 会员价 × 店铺满减 | 可叠加；会员价参与满减门槛判断的口径 = 折后价 |
| 积分抵扣 | 永远最后计算，抵扣上限 30%（06） |

**计算顺序（固定）**：SKU 直降 → 店铺满减/满折 → 店铺券 → 跨店满减 → 平台券 → 积分抵扣 → 最终实付。

### 3.3 分摊规则（P0）

- 店铺级/平台级优惠必须**按金额比例分摊到 SKU**（售后退款需按分摊额退）。
- 分摊取整规则：分为单位，逐项分摊后尾差给金额最大的 SKU（保证 Σ分摊 = 优惠总额）。
- 分摊明细写入订单快照（14），售后按《20/21》退还对应分摊额。

### 3.4 最优组合推荐（P1）

- 默认按「用户实付最低」自动勾选；多方案等价时优先勾「可退换的券」（优先消耗临期券）。
- 用户可手动改选；改选后实时重算（19-5-2 接口）。

| 条目 | 需求 | 优先级 |

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 优惠活动在结算中过期 | 已下单的按快照成交；未下单的重算并提示 |
| 券被并发使用 | 券核销原子化（25），失败回退整单算价 |
| 分摊后某 SKU 金额 ≤0 | 保底 0.01 元，差额由其他 SKU 吸收（尾差规则） |
| 规则配置冲突（互斥叠加错误配置） | 配置校验器：保存时模拟算价校验，禁止矛盾配置上线 |
| 算价服务超时 | 结算页禁用提交（46），不展示不确定价格 |

## 6. 数据与埋点

- 事件：`price_calc(skus, scheme)` / `discount_scheme_change(user 改选)`
- 指标：各层优惠使用率、优惠金额结构、算价 QPS 与耗时、对账差异数（目标 0）、资损护栏触发次数。

## 7. 依赖与接口

- 依赖：08 SKU 价格、25/26/28 优惠资产、06 积分/会员。
- 提供：`算价（详情/购物车/结算三入口统一）`、`快照锁定与重放`。
