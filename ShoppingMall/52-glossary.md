# 52 - 术语表

> 全套 PRD 统一术语。各文档不再重复定义，直接引用。

## 1. 商品域

| 术语 | 定义 |
|---|---|
| SPU | Standard Product Unit，标准产品单元（商品主体） |
| SKU | Stock Keeping Unit，最小销售单元（规格组合），价格/库存归属 |
| 类目 | 商品的层级组织（后台类目 L1-L4，仅叶子可发布） |
| 前台类目 | 面向用户的运营导航类目（与后台类目映射） |
| 销售属性 | 参与 SKU 组合的属性（颜色/尺码） |
| 关键属性 | 参与搜索筛选的结构化属性 |
| 划线价 | 参考展示价（禁止虚构，43 违规项） |
| 到手价 | 应用全部叠加优惠后的最终价（19） |
| 动销率 | 有销量商品 / 在售商品 |
| 价保 | 活动期间买贵退差价的承诺（28） |

## 2. 交易域

| 术语 | 定义 |
|---|---|
| 拆单 | 一次下单按规则生成多个子订单（跨店/分仓） |
| 价格快照 | 下单时锁定的金额与优惠分摊明细（不可变） |
| 预占（锁库存） | 下单未支付期间锁定库存（15 分钟超时释放） |
| 实扣 | 支付成功后库存转已扣减态 |
| 超时关单 | CREATED 订单未支付到期自动关闭 |
| 幂等键 | 防重复提交的唯一标识（49） |
| GSP 计费 | 广告按「下一名出价+0.01」计费（44） |
| 质量分 | 广告排名因子（历史 CTR/CVR×相关性） |

## 3. 售后域

| 术语 | 定义 |
|---|---|
| 仅退款 | 不退货的退款（未收到货/协商一致等场景，20） |
| 退货退款 | 买家寄回商品后退款（21） |
| 换货 | 同 SKU 不同规格的更换（21） |
| 仲裁 | 平台介入的纠纷裁决（22） |
| 举证期 | 仲裁中双方提交证据的时限（48h） |
| 验收 | 商家对退回商品的检查（合格/不合格） |
| 默认好评 | 确认收货 15 天未评价系统自动好评（23） |
| DSR | 描述/服务/物流三维店铺评分（36） |
| 追评 | 首评后 30 天内的补充评价（23） |

## 4. 营销域

| 术语 | 定义 |
|---|---|
| 券模板 / 用户券 | 活动定义 / 用户持有的券实例（25） |
| 核销 | 券在支付成功后真正消耗 |
| 跨店满减 | 平台级多店铺凑单满减（28，19 分摊） |
| 分摊 | 层级优惠按金额比例摊到 SKU（售后按分摊退） |
| 秒杀库存池 | 从主库存划拨的活动独立库存（26） |
| 候补 | 售罄后排队等释放库存（26） |
| 定金/尾款 | 预售两段付款（27，定金违约不退） |
| 成团 | 拼团人数满足（27） |
| 冷启动 | 新品/新店初始流量配额期（12，14 天） |

## 5. 商家与履约域

| 术语 | 定义 |
|---|---|
| 保证金 | 入驻缴纳的可扣划担保资金（32） |
| 电子面单 | 承运商标准快递单（取号-打印-绑定订单，37） |
| 虚假发货 | 有单号无揽收轨迹（34-4-7/43） |
| 发货拦截 | 取消/改址时对未出库订单的拦截（17/34） |
| 结算单 | 周期性货款结算明细（35） |
| 佣金 | 平台技术服务费（类目费率，35） |
| 冲抵 | 退款从结算/余额中扣回（35） |
| 负应收 | 退款 > 可结算额时挂账待扣（35） |
| 48h 发货 | PAID 后 48 小时内发货的平台规则（34） |

## 6. 治理与支撑域

| 术语 | 定义 |
|---|---|
| 信用分 | 用户/商家行为信用评分（41） |
| 挑战 | 风控的二次验证动作（验证码/滑块，41） |
| 机审 / 人审 | 自动审核 / 人工审核（42） |
| 扣分制 | 违规累计 12 分处罚体系（43） |
| 频控 | 通知/行为的频率限制（40/41） |
| 削峰 | 高并发排队缓冲（26/46） |
| 降级 L1-L4 | 非功能故障分级预案（46） |
| 资损护栏 | 防止优惠/补贴配置事故的兜底校验（19-4-5） |
| 通道 | 支付渠道（余额/第三方）（15） |
| 差错工单 | 对账差异的处理工单（15/35） |

## 7. 通用缩写

| 缩写 | 全称 |
|---|---|
| GMV | Gross Merchandise Volume，成交总额 |
| MTU | Monthly Transacting Users，月交易用户 |
| ARPU | Average Revenue Per User |
| CTR / CVR | 点击率 / 转化率 |
| ROI | 投资回报率（广告场景） |
| GPM | 千次观看成交额（直播） |
| WMS | 仓库管理系统（商家侧） |
| ISV | 独立软件服务商（第三方工具商） |
| FAQ | 常见问题 |
| P0/P1/P2 | 需求优先级（02 规范） |
