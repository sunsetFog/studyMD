# 21 - 退货退款与换货

## 1. 需求背景与目标

- **背景**：退货退款是逆向链路主体，涉及「资金 + 物流 + 商品」三流；换货覆盖尺码类高频需求。
- **目标**：退货申请到退款到账平均 ≤7 天；逆向物流揽收率 ≥95%。
- **非目标**：不做上门取件预约时段管理（P2 由 37 扩展）；不做跨境退货（P2）。

## 2. 适用条件

| 条件 | 规则 |
|---|---|
| 窗口期 | 确认收货后 7 天内申请（08 售后模板 7/15 天；不支持售后的商品入口不可见） |
| 商品状态 | 不影响二次销售（商家验收标准见 4.2）；定制类/生鲜/贴身衣物不适用（08 类目配置） |
| 运费承担 | 7 天无理由：买家承担；质量问题/发错货：商家承担（含来回） |
| 换货 | 仅支持同 SKU 不同规格（尺码/颜色），不支持换其他商品 |

## 3. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 21-3-1 | 申请流程：选退货退款/换货 → 原因（枚举 15 项）+ 凭证（≤9 图/1 视频）→ 提交 | P0 |
| 21-3-2 | 商家审核（24h，超时自动同意）：同意生成退货指引（地址/时效）或驳回（附原因） | P0 |
| 21-3-3 | 逆向物流：买家自行寄回，或使用平台合作寄件（37 提供运单，运费在线付/商家到付） | P0/P1 |
| 21-3-4 | 填写运单号：跟踪物流轨迹（37），签收后触发商家验收 | P0 |
| 21-3-5 | 商家验收：合格→执行退款（按 19 分摊+运费）；不合格→驳回并说明（举证照片）→ 买家可仲裁（22） | P0 |
| 21-3-6 | 超时规则：商家收到货 72h 未验收 → 自动验收合格并退款 | P0 |
| 21-3-7 | 换货流：验收合格 → 商家寄出换货商品（34 发货）→ 新物流单跟踪 → 完成 | P1 |
| 21-3-8 | 退款金额规则：商品分摊额 + 质量问题含运费；买家责任扣除商家垫付运费 | P0 |
| 21-3-9 | 退货提醒：商家同意后 7 天未寄回 → 自动关闭申请（可再申请） | P0 |

## 4. 流程

```
买家申请 → 商家审核(24h超时自动) → 同意 → 买家寄回(7天限时)
 → 商家验收(72h超时自动合格)
    ├─ 合格 → 退款(15) / 换货寄出 → 完成
    └─ 不合格 → 驳回(举证) → 买家接受 或 → 22 平台仲裁
```

### 4.2 验收标准（商家侧展示，平台规则 43 约束）

- 允许拒收情形：使用痕迹影响二次销售、配件缺失、人为损坏、水洗。
- 禁止拒收情形：拆封即拒（7 天无理由前提）、包装轻微破损、商品本身质量问题（应转商家责任运费）。
- 驳回必须附实拍凭证，无凭证驳回 → 直接进入平台复核（自动）。

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 退货件运输丢失 | 买家凭寄件凭证由承运方责任；平台仲裁兜底（22） |
| 验收争议（商家说损坏买家说没有） | 22 仲裁：双方举证，物流开箱记录优先 |
| 换货商品缺货 | 转退款（买家确认）或等待 ≤7 天 |
| 退款与积分/券回冲 | 同 20-4-5 |
| 超窗口期申请 | 入口关闭，引导客服特殊通道（39，仅质量问题特殊处理） |

## 6. 数据与埋点

- 事件：`return_apply(type, reason)` / `seller_audit(result)` / `return_shipped` / `acceptance(result)` / `refund_success`
- 指标：退货率（类目/店铺维度进 36 评分）、验收合格率、驳回→仲裁率、逆向物流时效、换货成功率。

## 7. 依赖与接口

- 依赖：15/18/25/06 回冲、37 逆向物流、22 仲裁、34 换货发货、40 通知。
- 提供：`退货单 CRUD`、`验收结果上报`（39 工单可关联）。
