# 49 - 关键接口约定与异常边界

> 本篇定义全平台接口与数据的全局技术性约定（产品侧约束），各 PRD 引用不重复。

## 1. 金额与精度（P0）

- 所有金额**以「分」为最小单位存储与计算**（整数），展示层转元。
- 优惠分摊取整：逐项四舍五入，尾差归最大金额项（19）。
- 浮点计算禁止（算价引擎 19 内部用整数运算）。

## 2. 幂等性（P0，全平台强约束）

| 操作 | 幂等键 | 重复行为 |
|---|---|---|
| 创建订单（14） | 客户端生成 `request_id` | 返回已创建订单 |
| 支付回调（15） | 渠道流水号 | 直接返回成功，不重复入账 |
| 库存释放（18） | `order_no + release` | 二次释放无操作 |
| 优惠券核销/返还（25） | `order_no + coupon_id` | 二次操作无操作 |
| 取消订单（17） | `order_no + cancel` | 返回已取消态 |
| 结算批任务（35） | `seller_id + period + version` | 重跑不重复生成 |
| 消息发送（40） | `event_id + user_id` | 去重 |
| 提现（07） | 客户端 `request_id` | 返回进行中/已完成 |

**实现约定**：幂等键 + 状态机双重防护——「接口幂等」防重放，「状态机校验」防非法重放（如已 PAID 订单重放 CREATED 建单必须拒绝）。

## 3. 并发控制（P0）

| 场景 | 策略 |
|---|---|
| 库存扣减（18） | 原子操作（行级锁/原子指令），禁止读算写 |
| 券领取（25） | 原子扣减库存池 |
| 订单状态变更（16） | 乐观锁（状态前置校验 + 版本号） |
| 同账户资金操作（07/35） | 账户级串行化（单账户排队） |
| 成团判定（27） | 团锁：成团期间禁止成员退款 |
| 秒杀（26） | 前置排队削峰 + 原子扣减 |

## 4. 接口通用约定（P0）

| 项 | 约定 |
|---|---|
| 错误码 | 分段：`1xxxx` 参数、`2xxxx` 业务规则、`3xxxx` 权限/登录、`4xxxx` 风控、`5xxxx` 系统；业务错误码表统一维护 |
| 错误文案 | 面向用户文案与错误码分离（文案可热更）；禁止暴露内部信息（表名/堆栈） |
| 防枚举 | 不存在资源返回「无权限」而非「不存在」（03） |
| 分页 | 游标分页（大数据量列表），页码分页仅限后台 |
| 超时重试 | 客户端重试必须携带同一幂等键；非幂等接口禁止自动重试 |
| 限流响应 | 429 语义 +「稍后重试」文案（26 排队场景除外） |
| 时间 | 服务端时间为准；客户端倒计时仅展示（16） |

## 5. 数据一致性（P0）

| 机制 | 应用 |
|---|---|
| 订单金额快照（14/19） | 价格/优惠以快照为准，事后变更不影响订单 |
| 状态事件订阅 | 订单状态变更为事实源，下游（结算/积分/消息）订阅消费 |
| 最终一致性兜底 | 每日对账任务：订单-库存-资金-券四方对账（15/18/25/35），差异生成差错工单 |
| 消息可靠投递 | 本地消息表 + 重试；消费幂等（2 节约定） |

## 6. 安全基线（P0，引用 32）

- 传输加密（HTTPS 全站）、密码哈希加盐、敏感字段（证件/手机号）加密存储 + 脱敏展示。
- 接口防重放：时间戳 + 签名（开放接口与回调）。
- 回调验签：渠道回调强制验签（15），伪造回调拒绝。
