# 09 - 商品详情页

## 1. 需求背景与目标

- **背景**：详情页是转化核心场，信息结构决定决策效率；同时是营销/评价/服务的聚合入口。
- **目标**：详情页首屏 LCP ≤ 1.5s（46）；加购转化率（详情页 UV→加购）≥ 8%。
- **非目标**：不做 AR 试穿/3D 展示（P2）。

## 4. 关键规则

- **价格展示一致性**：详情页到手价与结算页价格计算口径必须一致（19）；不一致以结算页为准并提示。
- **评价摘要规则**：好评率 = 近 90 天四/五星占比；不足 10 条评价不展示好评率（防小样本误导，23）。
- **库存展示**：「有货/仅剩 n 件/缺货」三态；精确库存数对买家隐藏（防爬虫与竞对套利）。
- **违规商品**：违规下架后详情页保留 7 天供用户看（已购用户），附「商品已下架」说明（43）。

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 价格/库存接口超时 | 价格区展示兜底「加载中」禁用按钮，禁止展示旧价（防误导）；46 降级 |
| SKU 全部缺货 | 购买按钮变「到货提醒」（40 订阅通知，P1） |
| 详情图违规被审核摘除 | 展示审核替换图（42） |
| 商品被换绑类目 | 页面缓存版本号校验，强制刷新 |

## 6. 数据与埋点

- 事件：`detail_view(sku_id, source)` / `sku_select` / `add_cart_click` / `buy_now_click` / `share_click`
- 指标：详情页 UV、停留时长、CTR 漏斗（来源→加购→下单）、首屏耗时、按钮点击热区分布。

## 7. 依赖与接口

- 依赖：商品（08）、库存（18）、价格引擎（19）、评价（23）、店铺（36）。
- 提供：`详情页聚合接口`（一次请求聚合主数据，减少串行）。
