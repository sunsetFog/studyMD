# 30 - 内容种草（图文/短视频信息流）

## 1. 需求背景与目标

- **背景**：内容流（逛逛类）承担「种草→拔草」的种草流量，与搜索/推荐（12）互补，延长用户时长。
- **目标**：内容流人均使用时长 ≥3 分钟；内容→商品点击转化 ≥8%。
- **非目标**：不做创作者激励分成体系（P2）；不做社交关系链（关注/粉丝 P1 最小集）。

## 2. 用户故事

- 作为买家，我想要看穿搭/好物分享内容，以便发现值得买的商品。
- 作为创作者，我想要发布图文/视频并挂商品链接，以便分享带货。
- 作为平台，我想要内容合规审核与虚假种草识别，以便内容生态可信。

## 3. 内容形态与结构

| 形态 | 组成 | 优先级 |
|---|---|---|
| 图文笔记 | 封面图 + 标题（≤30 字）+ 正文（≤1500 字）+ 挂链商品 ≤10 | P1 |
| 短视频 | 视频封面/时长 ≤3 分钟 + 标题 + 挂链商品 | P1 |
| 合集 | 创作者整理专题合集 | P2 |

## 4. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 30-4-1 | 发布：创作者（实名用户）发布图文/视频，挂链商品必须为在售 SKU（08 校验） | P1 |
| 30-4-2 | 信息流：双列瀑布流；个性化（12 推荐共用行为体系）+ 内容质量分层 | P1 |
| 30-4-3 | 互动：点赞/评论（机审）/收藏（48 收藏夹）/分享 | P1 |
| 30-4-4 | 挂链点击：跳商品详情（09），归因 `channel=content`（GMV 归因） | P1 |
| 30-4-5 | 关注体系（最小集）：关注创作者、个人主页（48 聚合发布内容） | P1 |
| 30-4-6 | 审核：机审（图文 OCR/视频抽帧/标题）+ 高曝光内容加审（42）；广告软文标识 | P1 |
| 30-4-7 | 虚假种草治理：批量同模板内容识别、黑产账号识别（41）、代写代发举报通道 | P1 |
| 30-4-8 | 「好物体验」标记：真实购买该商品的用户发布内容加「已购」标识（可信度） | P2 |

## 5. 流程

```
发布（实名校验）→ 机审 → 过审上架 → 分发（信息流/搜索内容聚合）
 → 用户互动/挂链点击 → 数据回流 → 质量分层调整分发
```

## 6. 异常与边界

| 场景 | 处理 |
|---|---|
| 挂链商品下架 | 内容保留，链接置灰「已下架」 |
| 内容违规（涉政/软色情/虚假宣传） | 42 拦截 → 删除 + 43 处罚（发布权限阶梯） |
| 爆款内容引发流量涌入 | 分发限速 + CDN 扩容（46） |
| 评论区攻击/网暴 | 举报优先处理（43），评论折叠 |

## 7. 数据与埋点

- 事件：`feed_view(content_id)` / `content_click(product)` / `like/comment/collect/share`
- 指标：人均时长、互动率、挂链 CTR、内容渠道 GMV、违规内容拦截率、创作者活跃数（周更创作者）。

## 8. 依赖与接口

- 依赖：08 商品链接校验、12 行为数据、42 审核引擎、40 通知。
- 提供：`内容流接口`、`创作者主页数据`。

## 9. 开放问题

- 创作者是否需入驻门槛（粉丝/信用分门槛防批量营销号）？（转 51）
- 内容与直播（29）是否打通（直播间切片进内容流）？（转 51）
