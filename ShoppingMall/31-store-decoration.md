# 31 - 店铺装修（商家自运营页面）

## 1. 需求背景与目标

- **背景**：店铺页是商家自有阵地（复购/私域运营），装修自由度与规范约束需要平衡。
- **目标**：店铺页 LCP ≤2s（46）；装修使用率（活跃商家中）≥60%。
- **非目标**：不做自由代码级装修（模板组件化即可）；不做小程序独立装修（P2）。

## 2. 用户故事

- 作为商家，我想要用组件拼装我的店铺首页（海报/商品组/优惠券组），以便体现品牌感与转化。
- 作为买家，我想要快速找到店铺内的分类商品与优惠，以便高效逛店。

## 3. 店铺页结构（买家视角）

| 区块 | 内容 | 优先级 |
|---|---|---|
| 店铺头 | 店名/Logo/评分（36）/关注按钮/客服入口 | P0 |
| 公告栏 | 商家公告（≤200 字） | P1 |
| 优惠区 | 店铺券领取（25）/活动标签 | P0 |
| 装修内容区 | 模板组件流（见 4.1） | P0 |
| 全部商品 | 商品列表 + 类目筛选（33 商品分组） | P0 |

## 4. 功能需求

### 4.1 组件库（P0）

| 组件 | 说明 |
|---|---|
| 海报图 | 1-N 张轮播，可挂链（商品/活动页） |
| 商品组 | 选商品展示（手动选 ≤50 或按商品分组），支持列表/宫格样式 |
| 优惠券组 | 关联店铺券模板（25），一键领取 |
| 分类导航 | 跳店铺内分组（33） |
| 富文本 | 图文混排（合规审核 42） |
| 视频 | 店铺介绍视频 ≤3 分钟 |

### 4.2 装修能力（P0/P1）

| 条目 | 需求 | 优先级 |
|---|---|---|
| 31-4-1 | 拖拽式装修台：组件添加/排序/配置，实时预览（手机预览） | P0 |
| 31-4-2 | 组件挂链校验：仅可链到本店商品/页面（防导流 43） | P0 |
| 31-4-3 | 模板市场：官方模板一键套用 | P1 |
| 31-4-4 | 装修版本：保存草稿/发布，发布即时生效；支持回退上一版 | P0 |
| 31-4-5 | 组件数据：各组件点击率统计（45） | P1 |
| 31-4-6 | 端适配：装修一次，App/H5 自适应渲染 | P0 |

## 5. 流程

```
商家进装修台 → 拖拽组件+配置 → 保存草稿 → 预览 → 发布（机审图片/文案）
 → 生效 → 数据回流（组件点击率）
```

## 6. 异常与边界

| 场景 | 处理 |
|---|---|
| 组件引用的商品下架 | 组件自动隐藏空位（不白屏） |
| 引用的券活动结束 | 优惠区自动隐藏 |
| 装修图违规 | 发布审核拦截；线上巡查违规即时下线该组件（42/43） |
| 并发装修（主账号+子账号） | 版本锁：后保存者提示冲突合并（49） |
| 装修台渲染失败 | 提供降级：仅文字配置模式 |

## 7. 数据与埋点

- 事件：`decorate_save/publish` / `shop_view(seller_id)` / `component_click(type, position)`
- 指标：店铺页 UV/PV、装修使用率、各组件 CTR、装修页转化（店铺页→加购）。

## 8. 依赖与接口

- 依赖：33 店铺信息、25 券、08 商品、42 审核、45 数据。
- 提供：`店铺页渲染配置读取`（买家端）、`装修版本管理`。
