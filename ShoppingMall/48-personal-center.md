# 48 - 个人中心（我的）

## 1. 需求背景与目标

- **背景**：个人中心聚合「我的资产/订单/工具」，是复购与留存的关键页面。
- **目标**：个人中心日访问占比 ≥60% 活跃用户；核心工具（订单/退款进度）首屏直达。
- **非目标**：不做社交主页（30 关注主页独立）；不做游戏化签到玩法中心（06 签到仅入口）。

## 2. 页面结构（自上而下）

| 区块 | 内容 | 优先级 |
|---|---|---|
| 用户头部 | 头像/昵称/会员等级标识（06）/设置入口 | P0 |
| 资产条 | 余额（07）/积分（06）/优惠券（25）三宫格，点击直达 | P0 |
| 我的订单 | 4 状态入口（待付款/待发货/待收货/待评价，16）+ 全部订单 | P0 |
| 我的工具宫格 | 地址（38）/客服（39）/收藏夹/浏览足迹/领券中心（25）/会员中心（06） | P0 |
| 服务区 | 退款售后（20/21 列表）/发票（16-3-9）/问大家我的提问（24） | P0/P1 |
| 商家身份入口 | 「我是商家」（03 身份切换，P0） | P0 |
| 内容区 | 我发布的内容（30）/关注创作者（30） | P1 |
| 其他 | 设置（隐私/推送 40-4-2/退出） | P0 |

## 3. 功能需求

| 条目 | 需求 | 优先级 |
|---|---|---|
| 48-3-1 | 订单状态角标实时刷新（待办数量） | P0 |
| 48-3-2 | 收藏夹：商品收藏分组、降价提醒（P1：40 订阅） | P0/P1 |
| 48-3-3 | 浏览足迹：按天分组，可清空（隐私） | P1 |
| 48-3-4 | 设置：推送开关（40）、个性化推荐开关（12-4-7）、账号注销入口（32 级联动 05） | P0 |
| 48-3-5 | 退款/售后进度聚合列表（20/21 单据） | P0 |
| 48-3-6 | 身份切换：买家 ↔ 商家后台（32），无商家资质则引导入驻 | P0 |

## 4. 异常与边界

| 场景 | 处理 |
|---|---|
| 资产数据加载慢 | 分层加载：资产条独立接口，失败显示「--」可刷新（46） |
| 注销前置校验 | 余额清零/订单完结/纠纷完结校验（07/16/22），不满足则阻断并说明 |
| 收藏商品下架 | 列表置灰「已下架」可找相似（12） |
| 商家身份切换中订单操作 | 身份独立会话；切换不中断买家会话任务 |

## 5. 数据与埋点

- 事件：`profile_view` / `asset_click(type)` / `order_entry(status)` / `tool_click(name)`
- 指标：资产条点击率、订单入口分布、工具使用率、注销发起量（体验信号）、复购从个人中心入口的占比。

## 6. 依赖与接口

- 依赖：06/07/25 资产、16 订单、20/21 售后、38/39/40 工具、30 内容。
- 提供：`个人中心聚合接口`（首屏一次拉取）。
