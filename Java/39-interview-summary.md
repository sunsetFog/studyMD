# 39 · 高频面试题与学习路线总结

## 一、高频面试题精选（按板块）

### 基础与 OOP

**1. == 和 equals 区别？为什么重写 equals 必须重写 hashCode？**
== 引用比较（基本类型值比较）；equals 默认 ==，重写后按内容。契约：equals 相等必须 hashCode 相等，否则 HashMap/HashSet 查找失效（09 篇）。

**2. String 为什么不可变？有什么好处？**
final byte[] + 无修改方法。好处：常量池安全共享、hashCode 缓存、线程安全、可作 Map key（04 篇）。

**3. 重载与重写区别？**
重载同类签名不同编译期定；重写父子签名相同运行期动态绑定（07 篇）。

**4. 接口和抽象类怎么选？**
is-a 且共享状态/骨架 → 抽象类；能力契约/多实现/回调 → 接口（08 篇）。

**5. Java 是值传递还是引用传递？**
只有值传递：基本类型拷贝值，对象拷贝引用（地址）——方法内 reassign 不影响外部，但可改对象内部状态（05 篇）。

### 集合与泛型

**6. HashMap 原理？JDK8 做了什么优化？**
数组+链表+红黑树；链长≥8 且容量≥64 树化；扰动函数减少碰撞；2 倍扩容（16 篇）。

**7. ConcurrentHashMap 怎么保证并发安全？**
JDK8 CAS + synchronized 锁单桶头节点；size 用 CounterCell 分片；key/value 禁 null（24 篇）。

**8. ArrayList 和 LinkedList 区别？何时选？**
数组 O(1) 随机访问 vs 链表 O(1) 头尾增删；实际 90% 选 ArrayList（缓存友好）（16 篇）。

**9. PECS 是什么？**
Producer Extends（读）Consumer Super（写），既读又写用精确类型（17 篇）。

**10. fail-fast 是什么？**
迭代器检测结构性修改抛 CME；并发容器换弱一致迭代器（16/24 篇）。

### 并发（面试权重最高）

**11. synchronized 原理与锁升级？**
对象头 Mark Word；偏向→轻量级（CAS 自旋）→重量级（OS mutex）；15 起移除偏向锁（20 篇）。

**12. volatile 语义？能保证原子性吗？**
可见性 + 禁止重排，**不保证原子性**（count++ 仍竞态）；DCL 单例必加的原因是禁止「分配-初始化-赋值」重排（21 篇）。

**13. 线程池参数与执行流程？**
七参数；先核心线程→入队→扩最大线程→拒绝策略（23 篇）。追问 Executors 隐患：无界队列 OOM。

**14. ThreadLocal 原理与内存泄漏？**
每个 Thread 持 ThreadLocalMap，key 弱引用 value 强引用 → 线程池复用不 remove 则泄漏；用完必 remove。虚拟线程时代用 ScopedValue 替代（25 篇）。

**15. CAS 是什么？ABA 问题？**
compareAndSwap CPU 原子指令；失败自旋。ABA 用版本号（AtomicStampedReference）（21 篇）。

**16. 虚拟线程是什么？适合什么场景？**
JVM 调度轻量线程，阻塞 IO 自动让出载体线程；IO 密集高并发适合，CPU 密集/无池化意识（25 篇）。

### JVM

**17. JVM 内存区域？**
线程私有：栈/PC/本地方法栈；共享：堆（新生代 Eden+S0+S1/老年代）、元空间（30 篇）。

**18. 对象什么时候进老年代？**
年龄 15 / 动态年龄判定 / 大对象 / 空间担保（30 篇）。

**19. G1 与 CMS 区别？**
G1 Region 化 + 可预测停顿 + 不产生碎片；CMS 标记清除有碎片已移除（32 篇）。

**20. 如何排查 OOM / CPU 100%？**
OOM：dump 参数 + MAT Leak Suspects；CPU：top -Hp → jstack 十六进制 → 栈定位（35 篇）。

**21. 双亲委派是什么？为什么要打破？**
委派父加载器防核心类篡改与保证唯一；打破场景：SPI/容器隔离/热部署（31 篇）。

### 新特性

**22. Record 是什么？什么时候用？**
不可变数据载体一行生成全套；DTO/值对象用，JPA 实体不用（10 篇）。

**23. sealed 密封类解决什么问题？**
受控继承 + switch 穷举检查 → ADT 建模（36 篇）。

## 二、答题方法论

1. **定义 → 机制 → 场景 → 陷阱**四段式
2. **带版本**：JDK 8 vs 17 vs 21 行为差异体现深度
3. **主动引申**：答 HashMap 顺带讲 ConcurrentHashMap 对比
4. **讲事故**：「线上遇过 XX 问题，排查路径是…」最有说服力
