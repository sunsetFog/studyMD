## 第一部分：考试概况（必读）

### 考试形式
- [ ] **闭卷笔试**，满分 **150 分**，考试时间 **150 分钟**
- [ ] 三部分内容比例：马哲约 28% / 毛概与中特约 65% / 时事政治约 7%

### 题型与分值
| 题型 | 题量 | 每题分值 | 合计 |
|------|------|---------|------|
| 单项选择题 | 40 题 | 2 分 | 80 分 |
| 辨析题 | 2 题 | 10 分 | 20 分 |
| 简答题 | 3 题 | 10 分 | 30 分 |
| 论述题 | 1 题 | 20 分 | 20 分 |

### 拿分策略
- [ ] **选择题是重点**（80 分，占 53%）：靠熟记知识点，尤其是"第一个""根本""本质""核心"这类关键词
- [ ] **辨析题**：先判断对错，再讲理由，**错误的一定要说明为什么错、正确表述是什么**
- [ ] **简答题**：分点作答，写关键词即可，**要点全比字多更重要**
- [ ] **论述题**：先背原理，再联系实际（结合材料／时事）。**原理 + 联系实际 = 高分**

## 第二部分：马克思主义哲学原理

### 1. 绪论

#### 1.1 哲学与世界观
- [ ] **世界观**：人们对整个世界的总的看法和根本观点
- [ ] **哲学**：系统化、理论化的世界观，是世界观和方法论的统一
- [ ] **方法论**：人们认识世界和改造世界的根本方法
- [ ] 世界观决定方法论，方法论体现世界观

#### 1.2 哲学基本问题
- [ ] **哲学基本问题**：思维和存在（意识和物质）的关系问题
- [ ] **第一方面**（划分唯物/唯心的标准）：思维和存在谁是第一性
  - **唯物主义**：物质第一性，意识第二性
  - **唯心主义**：意识第一性，物质第二性
- [ ] **第二方面**（划分可知论/不可知论的标准）：思维能否正确认识存在
  - **可知论**：世界可以认识
  - **不可知论**：世界不能或不能完全认识

#### 1.3 唯物主义的历史形态
- [ ] **古代朴素唯物主义**：如"水是万物本原"（把物质归结为具体物质形态）
- [ ] **近代形而上学唯物主义**：把物质归结为原子，机械、孤立、片面
- [ ] **辩证唯物主义和历史唯物主义**（马克思主义哲学）：最科学、最彻底的唯物主义

#### 1.4 唯心主义的两种形式
- [ ] **主观唯心主义**：把人的主观精神当本原（"心外无物""存在即被感知"）
- [ ] **客观唯心主义**：把"绝对精神""神""理念"当本原（"理在事先""上帝创造世界"）

#### 1.5 马克思主义哲学的基本特征
- [ ] **阶级性**：马克思主义哲学是无产阶级的世界观和方法论
- [ ] **科学性**：正确揭示自然、社会和思维发展的普遍规律
- [ ] **实践性**：强调实践是认识的基础（**最显著的特征**）
- [ ] 科学性、革命性、实践性的统一

#### 1.6 辩证唯物主义与历史唯物主义
- [ ] **辩证唯物主义**：辩证的唯物论 + 唯物辩证法 + 辩证唯物主义认识论
- [ ] **历史唯物主义**：把唯物论贯彻到社会历史领域

### 2. 物质和意识

#### 2.1 物质及其存在形式
- [ ] **物质的唯一特性**：客观实在性
- [ ] **列宁对物质的定义**：物质是标志客观实在的哲学范畴，通过感觉感知，不依赖于我们的感觉而存在
- [ ] **运动是物质的根本属性**：物质是运动的物质，运动是物质的运动
- [ ] **静止是运动的特殊状态**：相对静止，是运动的衡量尺度
- [ ] 物质世界是绝对运动与相对静止的统一

#### 2.2 时间与空间
- [ ] **时间**：物质运动的持续性、顺序性，**一维性**
- [ ] **空间**：物质运动的广延性、伸张性，**三维性**
- [ ] 时间和空间是运动着的物质的存在形式，是客观的

#### 2.3 意识的起源、本质与作用
- [ ] **起源**：
  - 意识是**自然界长期发展的产物**
  - 意识是**社会劳动的产物**（劳动在意识产生中起决定作用）
- [ ] **本质**：意识是**人脑的机能**，是**客观存在的主观映象**
- [ ] **能动作用（意识的反作用）**：
  - 意识具有**目的性、计划性**
  - 意识具有**创造性**
  - 意识能**指导实践、改造客观世界**
  - 意识能**调节和控制人体生理活动**
- [ ] **发挥主观能动性必须以尊重客观规律为前提**

#### 2.4 世界的物质统一性
- [ ] **世界是物质的**，世界的统一性在于它的物质性
- [ ] 物质决定意识，意识反作用于物质（**辩证关系**）
- [ ] **方法论**：一切从实际出发，实事求是

### 3. 物质世界的联系与发展

#### 3.1 联系的观点
- [ ] **联系的含义**：事物之间及事物内部诸要素之间的相互影响、相互制约和相互作用
- [ ] **联系的特性**：
  - **客观性**：联系是事物本身固有的，不以人的意志为转移
  - **普遍性**：任何事物都与周围事物联系着
  - **多样性**：直接联系与间接联系、内部联系与外部联系、本质联系与现象联系等
- [ ] **方法论**：用联系的观点看问题，反对孤立、片面

#### 3.2 发展的观点
- [ ] **发展的实质**：新事物的产生和旧事物的灭亡
- [ ] **发展的方向**：前进的、上升的
- [ ] **发展的道路**：曲折的，**事物发展是前进性与曲折性的统一**
- [ ] **方法论**：用发展的观点看问题，与时俱进

#### 3.3 量变与质变
- [ ] **量变**：事物量的规定性的变化（数量增减、场所变更）
- [ ] **质变**：事物根本性质的变化
- [ ] **辩证关系**：
  - 量变是质变的必要准备
  - 质变是量变的必然结果
  - 质变引起新的量变
- [ ] **方法论**：要重视量的积累，又不失时机促成质变

#### 3.4 对立统一规律（辩证法的核心）
- [ ] **矛盾**：事物之间及事物内部诸要素之间的对立统一关系
- [ ] **矛盾的两种属性**：
  - **同一性**：矛盾双方相互依存、相互转化
  - **斗争性**：矛盾双方相互排斥、相互对立
  - 同一性是有条件的（相对），斗争性是无条件的（绝对）
- [ ] **矛盾是事物发展的动力**：
  - **内部矛盾（内因）**是发展的根本原因
  - **外部矛盾（外因）**是发展的条件
- [ ] **矛盾的普遍性与特殊性**：
  - **普遍性**（共性）：矛盾存在于一切事物和发展过程中
  - **特殊性**（个性）：不同事物的矛盾各有特点
  - 关系：共性与个性、一般与个别的关系，即矛盾普遍性与特殊性的统一
- [ ] **主要矛盾与次要矛盾**：
  - 主要矛盾居于支配地位，起决定作用
  - 方法论：抓主要矛盾（**重点论**）＋ 兼顾次要矛盾（**两点论**）
- [ ] **矛盾的主要方面与次要方面**：矛盾的性质由主要方面决定
- [ ] **方法论**：**两点论与重点论的统一**

#### 3.5 否定之否定规律
- [ ] **事物的否定**是包含肯定的否定（辩证否定观），是**扬弃**（既克服又保留）
- [ ] 事物发展经历两次否定、三个阶段：**肯定 → 否定 → 否定之否定**
- [ ] 表现为**螺旋式上升、波浪式前进**

#### 3.6 原因与结果、必然与偶然、可能与现实
- [ ] **原因与结果**：引起与被引起，相互依存、相互转化
- [ ] **必然与偶然**：必然性通过偶然性开辟道路
- [ ] **可能与现实**：现实性着眼于"现在"，可能性着眼于"未来"

#### 3.7 唯物辩证法的基本范畴（五对）
1. [ ] 原因与结果
2. [ ] 必然性与偶然性
3. [ ] 可能性与现实性
4. [ ] 现象与本质
5. [ ] 形式与内容

### 4. 实践与认识

#### 4.1 实践及其基本形式
- [ ] **实践的含义**：人们改造客观世界的一切物质活动
- [ ] **实践的基本特征**：客观物质性、自觉能动性、社会历史性
- [ ] **实践的三种基本形式**：
  - **生产实践**（最基本的）
  - **处理社会关系的实践**
  - **科学实验**

#### 4.2 认识与实践的关系
- [ ] **实践是认识的基础**（决定作用）：
  1. 实践是认识的**来源**
  2. 实践是认识发展的**动力**
  3. 实践是检验认识真理性的**唯一标准**
  4. 实践是认识的**目的和归宿**
- [ ] **认识对实践有反作用**：正确的认识指导实践成功，错误的认识导致失败

#### 4.3 认识的本质
- [ ] **认识的本质**：实践基础上主体对客体的能动反映
- [ ] 认识是**能动的、创造性的反映**（区别于机械反映论）

#### 4.4 认识的辩证过程
- [ ] **第一次飞跃**：从感性认识到理性认识
  - **感性认识**：感觉、知觉、表象（低级阶段，具体、生动、形象）
  - **理性认识**：概念、判断、推理（高级阶段，抽象、概括、深刻）
  - 二者关系：理性认识依赖于感性认识，感性认识有待发展为理性认识
- [ ] **第二次飞跃**：从理性认识到实践（**更重要**）
- [ ] 认识过程是**实践—认识—再实践—再认识**的无限循环、螺旋上升过程

#### 4.5 真理及其特性
- [ ] **真理**：人们对客观事物及其规律的正确反映
- [ ] **真理的客观性**：真理的内容是客观的，检验真理的标准（实践）是客观的
- [ ] **真理的绝对性（绝对真理）与相对性（相对真理）**：二者是辩证统一的
- [ ] **真理与谬误**：真理与谬误相互依存、相互转化，真理在同谬误斗争中发展
- [ ] **真理是具体的、有条件的**，真理面前人人平等

#### 4.6 实践是检验真理的唯一标准
- [ ] 这是由**真理的本性**（主观与客观相符合）和**实践的特点**（直接现实性）决定的
- [ ] 实践标准是确定性与不确定性的统一

### 5. 社会存在与社会意识

#### 5.1 社会存在
- [ ] **社会存在的含义**：社会物质生活条件的总和
- [ ] **构成**：
  - **地理环境**（自然条件）
  - **人口因素**
  - **物质资料生产方式**（**决定力量**）
- [ ] 生产方式是社会历史发展的决定力量

#### 5.2 社会意识
- [ ] **社会意识的含义**：社会精神生活的总和
- [ ] **从主体看**：个人意识、群体意识
- [ ] **从层次看**：
  - **社会心理**（低级，自发的，不系统的）
  - **社会意识形式**（高级，自觉的，理论化的）
- [ ] **从是否反映经济基础看**：
  - **意识形态**：政治、法律、道德、艺术、宗教、哲学（有阶级性）
  - **非意识形态**：自然科学、语言学、形式逻辑（无阶级性）

#### 5.3 社会存在与社会意识的辩证关系
- [ ] **社会存在决定社会意识**：社会意识是社会存在的反映，随社会存在变化而变化
- [ ] **社会意识具有相对独立性**：
  1. 社会意识变化与社会存在变化**不完全同步**（可能超前或滞后）
  2. 社会意识发展具有**历史继承性**
  3. 各种社会意识形式之间**相互影响、相互作用**
  4. 社会意识**对社会存在有能动的反作用**（最突出的表现）

### 6. 社会基本矛盾与历史发展

#### 6.1 社会基本矛盾
- [ ] **生产力与生产关系的矛盾**
- [ ] **经济基础与上层建筑的矛盾**
- [ ] 这两对矛盾是社会发展的根本动力

#### 6.2 生产力与生产关系
- [ ] **生产力**：人们改造自然、获得物质生活资料的能力
  - 要素：劳动者（**最活跃、最革命**）、劳动资料（生产工具是**标志**）、劳动对象
  - 科学技术是第一生产力
- [ ] **生产关系**：人们在生产过程中结成的不以人的意志为转移的经济关系
  - 构成：生产资料所有制（**基础、决定地位**）、人们在生产中的地位和关系、产品分配方式
- [ ] **辩证关系**：
  - 生产力决定生产关系
  - 生产关系反作用于生产力（**适应则促进，不适应则阻碍**）
- [ ] **生产关系一定要适应生产力状况的规律**

#### 6.3 经济基础与上层建筑
- [ ] **经济基础**：占统治地位的生产关系各方面的总和
- [ ] **上层建筑**：
  - **政治上层建筑**：政治制度、法律制度、国家政权等（国家政权是**核心**）
  - **思想上层建筑**：政治思想、法律思想、道德、宗教、哲学等
- [ ] **辩证关系**：
  - 经济基础决定上层建筑
  - 上层建筑反作用于经济基础（为自己的经济基础服务）
- [ ] **上层建筑一定要适应经济基础状况的规律**

#### 6.4 阶级与国家
- [ ] **阶级**：阶级的产生是生产力发展的结果，本质是经济关系的体现
- [ ] **国家的起源与本质**：国家是阶级矛盾不可调和的产物，本质是**阶级统治的工具**
- [ ] 国体与政体：国体决定政体，政体体现国体

#### 6.5 社会形态更替
- [ ] 社会形态：**原始社会 → 奴隶社会 → 封建社会 → 资本主义社会 → 社会主义社会 → 共产主义社会**
- [ ] 社会形态更替是**统一性与多样性**的统一、**必然性与选择性**的统一

#### 6.6 人民群众与个人的历史作用
- [ ] **人民群众是历史的创造者**：
  1. 是社会物质财富的创造者
  2. 是社会精神财富的创造者
  3. 是社会变革的决定力量
- [ ] **杰出人物**对历史发展有重要作用，但受社会历史条件制约
- [ ] **党的群众路线**：一切为了群众，一切依靠群众，从群众中来，到群众中去

#### 6.7 人的本质与人的价值
- [ ] **人的本质**：在其现实性上，是一切社会关系的总和（马克思）
- [ ] **人的价值**：社会价值（贡献）与自我价值（索取）的统一，**社会价值是主要方面**
- [ ] **人的自由全面发展**：是共产主义社会的根本特征

## 第三部分：毛泽东思想

### 7. 毛泽东思想概述

#### 7.1 毛泽东思想的形成与发展
- [ ] **形成**：土地革命战争时期（1927-1937），初步形成
- [ ] **成熟**：抗日战争时期（1937-1945），新民主主义革命理论成熟
- [ ] **发展**：解放战争及新中国成立后
- [ ] **1945 年党的七大**，确立毛泽东思想为党的指导思想

#### 7.2 毛泽东思想的科学内涵
- [ ] 是马克思列宁主义在中国的运用和发展
- [ ] 是被实践证明了的关于中国革命和建设的正确的理论原则和经验总结
- [ ] 是中国共产党集体智慧的结晶

#### 7.3 毛泽东思想的活的灵魂（三个基本方面）
- [ ] **实事求是**（精髓）
- [ ] **群众路线**（根本工作路线）
- [ ] **独立自主**

## 第六部分：答题方法与冲刺技巧

### 一、选择题（40 题 × 2 分 = 80 分）
- [ ] 抓关键词：**"根本""本质""核心""首要""基本""第一""标志"**——这些是高频考点
- [ ] 排除法：排除明显错误（偷换概念的选项）
- [ ] 时间线：注意不同理论的形成时间、确立大会

### 二、辨析题（2 题 × 10 分 = 20 分）
答题三步走：
1. [ ] **明确判断**：正确、错误或"片面"（**必须先表态**）
2. [ ] **说明理由**：正确的讲清原理；错误的指出错在哪、正确的表述是什么
3. [ ] **回到材料**：结合题目语言总结

模板：
> "这一观点是（不）正确的。① 从……原理看，……；② 从……方面看，……；③ 因此，正确的表述应该是……"

### 三、简答题（3 题 × 10 分 = 30 分）
- [ ] **分点作答**：用 1、2、3、4 或 ① ② ③ ④
- [ ] 写出**关键词**即可，不要求大段文字
- [ ] **宁多勿少**：能写几点就写几点（但别写错）
- [ ] 常见考点结构：三大法宝、三大活的灵魂、五位一体、四个全面、新发展理念

### 四、论述题（1 题 × 20 分 = 20 分）
- [ ] **先答原理**：写出相关理论（占分大头）
- [ ] **再联系实际**：结合材料 / 时事 / 社会实践
- [ ] **最后总结**：回扣问题，升华观点
- [ ] 分值高，多写多得分，注意条理清晰、分点作答

模板：
> "第一，（原理①②③）。第二，结合材料/实际，……。第三，因此，……。"

### 五、复习冲刺建议
- [ ] **抓大纲**：以考试大纲为准，不要盲目扩大范围
- [ ] **记关键词**：政治靠记忆，抓住每句话的关键词
- [ ] **刷真题**：近 3~5 年真题，感受题型和难度
- [ ] **背模板**：辨析、简答、论述都有固定答题结构
- [ ] **结合时事**：考前一个月集中看时事政治小册子

### 六、高频考点速记（冲刺必背）
- [ ] 哲学基本问题：思维和存在的关系
- [ ] 物质的唯一特性：客观实在性
- [ ] 辩证法的核心：对立统一规律
- [ ] 认识的基础：实践
- [ ] 检验真理的唯一标准：实践
- [ ] 人民群众是历史的创造者
- [ ] 毛泽东思想活的灵魂：实事求是、群众路线、独立自主
- [ ] 新民主主义革命三大法宝：统一战线、武装斗争、党的建设
- [ ] 社会主义本质：解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕
- [ ] 社会主要矛盾：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾
- [ ] 新发展理念：创新、协调、绿色、开放、共享
- [ ] 社会主义核心价值观：24 字
