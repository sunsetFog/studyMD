## 英语选择题答题技巧（必读）

1. **看空格前后，定考点**：先判断空格处要填什么词性——名词？动词？介词？还是连词？**词性对了，一半就赢了**。
2. **优先背"固定搭配"**：如 be good **at**、be interested **in**、look forward **to**、be used **to doing**，这类题**看到搭配直接选**，不要凭语感犹豫。
3. **动词题看"时间"和"主语"**：先看时间状语（now / yesterday / since 2010 / by last year），再确定时态；再看主语单复数，确定主动还是被动。
4. **谓语还是非谓语**：一句话只能有**一个谓语动词**。若句中已有谓语，后面动词就用**非谓语**（doing / done / to do）。
5. **从句看"缺什么"**：定语从句缺主语/宾语用 who/which/that，缺定语用 whose；状语从句看逻辑关系（因果、转折、条件）。
6. **不会也千万别空着**：成考选择**不倒扣分**，**必须全选满**，蒙一个也有 25% 正确率。

# 第一部分：语音知识

> **出题形式**：给出 4 个单词，选出划线部分（本文件用**加粗**表示）读音与其他三项不同的一项。
>
> **解题方法**：先按字母组合回忆发音规律，再逐一比对，**找出"异类"**即可。

### 第 1 题

选出划线部分读音与其他三项不同的一项。

A. gr**ea**t
B. br**ea**k
C. st**ea**k
D. m**ea**t

**答案：D**

**解析：** 本题考查字母组合 **ea** 的读音。
- **D 对**：meat 中 ea 读 **/iː/**。

# 第二部分：名词 / 冠词 / 代词 / 数词

### 第 21 题

There are many ____ in the field.

A. sheep
B. sheeps
C. sheepes
D. sheep's

**答案：A**

**解析：** 本题考查名词单复数。
- **A 对**：sheep（羊）**单复数同形**，many 后接复数，仍用 sheep。
- **B、C 错**：sheep 是不可规则变化的名词，**不加 -s / -es**。
- **D 错**：sheep's 是所有格形式，表示"羊的"，与句意不符。

---

### 第 22 题

I'd like ____, please.

A. two breads
B. two pieces of bread
C. two bread
D. two piece of breads

**答案：B**

**解析：** 本题考查不可数名词的数量表达。
- **B 对**：bread 是**不可数名词**，计数要用"数词 + 量词 + of + 名词"，且数词大于 1 时量词要用复数，故为 **two pieces of bread**。
- **A、C 错**：不可数名词 bread **不能直接加 -s**，也不能被数词直接修饰。
- **D 错**：数词 two 后量词 piece 必须用复数 **pieces**，且 bread 不能加 -s。

### 第 23 题

This is ____ bike. He rides it to school every day.

A. Tom
B. Tom's
C. Toms
D. Toms'

**答案：B**

**解析：** 本题考查名词所有格。
- **B 对**：表示"汤姆的自行车"，人名后加 **'s**，故用 Tom's。
- **A、C 错**：Tom 是人名，不能直接修饰名词，也不能加 -s。
- **D 错**：Toms' 是"多个叫 Tom 的人的"，与句意（He rides it）不符。

- **B、C 错**：children 本身已是复数，不能再加 -s，也不能直接作定语表示"孩子们的"。

### 第 25 题

He is ____ honest boy, and everyone likes him.

A. a
B. an
C. the
D. /

**答案：B**

**解析：** 本题考查不定冠词 a / an 的选择。
- **B 对**：**由读音决定**用 a 还是 an。honest 中 h **不发音**，第一个音素是元音 **/ɒ/**，故用 **an**。
- **A 错**：a 用于辅音音素开头的词前，honest 不是辅音开头。
- **C 错**：此处首次提到、泛指"一个诚实的男孩"，不用定冠词。
- **D 错**：可数名词单数前必须加冠词。

### 第 31 题

The weather in Beijing is colder than ____ in Guangzhou.

A. it
B. this
C. that
D. one

**答案：C**

**解析：** 本题考查代词 that 的指代用法。
- **C 对**：比较时，为避免重复，用 **that** 指代前面提到的**不可数名词或单数可数名词**（此处指 the weather）。
- **A 错**：it 指代同一个事物，不能用于此处的对比。
- **B 错**：this 指近处，指代不清。
- **D 错**：one 指代**可数名词**，weather 不可数。

# 第三部分：形容词 / 副词 / 介词

- **D 对**：句中有 **than**，说明是比较，用比较级 **taller**。

# 第五部分：情态动词与虚拟语气

### 第 86 题

# 附录：英语选择题答题技巧与高频考点速查

## 一、六大解题技巧

| 技巧 | 要点 | 举例 |
| --- | --- | --- |
| **① 定词性** | 先看空格处应填名词、动词、介词还是连词 | It's very kind ____ you. → 填 of |
| **② 背搭配** | 固定搭配"看到就选"，别凭语感猜 | be interested **in**、look forward **to** |
| **③ 看时间** | 找时间状语定时态 | since 2010 → 现在完成时 |
| **④ 看主被动** | 主语是执行者还是承受者 | The window ____ by Tom. → was broken |
| **⑤ 谓语唯一** | 一句只有一个谓语，其余用非谓语 | 已有谓语的句中动词用 doing / done / to do |
| **⑥ 从句缺啥补啥** | 定语从句缺主语/宾语用 who/which/that，缺状语用 when/where/why | the day ____ we met → when |

## 二、高频固定搭配速查表

| 搭配 | 含义 | 搭配 | 含义 |
| --- | --- | --- | --- |
| be good **at** | 擅长 | be interested **in** | 对……感兴趣 |
| be proud **of** | 为……骄傲 | be afraid **of** | 害怕 |
| be busy **with** | 忙于 | be famous **for** | 因……而闻名 |
| be full **of** | 充满 | be different **from** | 与……不同 |
| be satisfied **with** | 对……满意 | be responsible **for** | 对……负责 |
| be used **to doing** | 习惯于 | used **to do** | 过去常常 |
| look forward **to doing** | 期待 | look **up** | 查阅 |
| look **after** | 照顾 | look **for** | 寻找 |
| give **up** | 放弃 | give **in** | 屈服 |
| put **off** | 推迟 | put **on** | 穿上 |

## 三、高频语法考点速查

| 考点 | 记忆口诀 |
| --- | --- |
| **主将从现** | if / when / as soon as / until 引导的从句，**主句将来时，从句用一般现在时** |
| **现在完成时** | since + 时间点、for + 时间段、already、yet、ever、never、just 是标志 |
| **过去完成时** | by the end of + 过去时间、by the time + 过去从句 是标志 |
| **被动语态** | 结构 be + 过去分词；注意 make / see / hear 变被动要**还原 to** |
| **虚拟语气** | if 从句：现在→过去式（be 用 were）；过去→had done；将来→were to do / should do |
| **虚拟语气（should 型）** | suggest / advise / demand / order / It's necessary that + (should) do |
| **非谓语** | 主动 doing，被动 done，目的/将来 to do；介词后一律用 doing |
| **定语从句** | 指人 who/whom，指物 which，所属 whose，最高级/不定代词后只用 that |
| **主谓一致** | each / the number of / 时间金钱作主语→单数；a number of / police→复数 |

## 四、易错易混对比表（高频）

| 易混点 | 区别 | 示例 |
| --- | --- | --- |
| **some / any** | 肯定句、委婉请求用 some；疑问否定用 any | Would you like **some** tea? |
| **few / a few** | few＝几乎没有；a few＝有几个（都可数） | **few** people 几乎没人 |
| **little / a little** | little＝几乎没有；a little＝有一点（都不可数） | **little** time 几乎没时间 |
| **fewer / less** | fewer＋可数复数；less＋不可数 | **less** money / **fewer** books |
| **speak / say / tell / talk** | speak＋语言；say＋内容；tell＋sb.；talk＋with/about | **say** something to me |
| **spend / cost / pay / take** | 人 spend on / 物 cost / 人 pay for / It takes time to do | It **took** me an hour |
| **stop to do / stop doing** | to do＝停下（去做另一件事）；doing＝停止做 | stop **to rest** 停下休息 |
| **remember to do / doing** | to do＝记得去做（未做）；doing＝记得做过 | Remember **to lock** the door |
| **arrive in / at** | in＋大地点；at＋小地点 | arrive **in** Beijing |
| **in / on / at（时间）** | in＋年月季节；on＋具体某天；at＋钟点 | **on** Monday morning |
| **hard / hardly** | hard＝努力地/猛烈地；hardly＝几乎不 | It's raining **hard** |
| **make of / make from** | of 看得出原料；from 看不出原料 | Wine is made **from** grapes |

## 五、考前冲刺建议

1. **错题回看**：把带★的错题重做一遍，重点看**错因**（是搭配不熟，还是时态判断错）。
2. **搭配优先背**：固定搭配是"背了就得分"的部分，考前一周集中背**附录二的搭配表**。
3. **语法抓高频**：时态、被动、非谓语、从句、虚拟语气占选择题的大头，**优先保证这几类不丢分**。
4. **补全对话记应答**：感谢→You're welcome.；道歉→That's all right.；初次见面→How do you do?。
5. **做题节奏**：单选题平均**20-30 秒/题**，不确定的先标记跳过，最后统一回看。
6. **不留空**：选择不倒扣分，**全部答满**，不会的也要蒙一个。

> **最后提醒**：英语选择题提分靠的是"**语法规则 + 固定搭配**"，不是"语感玄学"。把这份文件的 200 道题做两遍、错题看三遍，你的选择题正确率一定会有明显提升。加油！
