# 38 - 面试题 30 道

> 答题方法论：先给**结论** → 再讲**原理/机制** → 最后落**实践/踩坑**。带 ⭐ 为高频必考。

## A. 基础（1-8）

**1. MySQL 体系结构分几层？⭐**
三层：连接层/服务层（解析、优化、执行）/引擎层 + 文件层。补充：8.0 移除查询缓存的原因（失效代价高）。→ 01

**2. InnoDB 和 MyISAM 区别？⭐**
事务、行锁、崩溃恢复、MVCC、聚簇索引。反问点：InnoDB 为什么没有全局 count 缓存（MVCC 语义）。→ 04

**3. 为什么推荐自增主键？UUID 有什么问题？⭐**
顺序写避免页分裂、二级索引膨胀、索引更小。分布式场景用雪花 ID。→ 21/19

**4. utf8mb4 和 utf8 区别？**
utf8 是 3 字节残缺版，emoji 存不了；8.0 默认 mb4。→ 20

**5. DROP/DELETE/TRUNCATE 区别？⭐**
回滚能力、触发器、自增重置、binlog 语义。→ 06

**6. NULL 相关的坑？**
三值逻辑、NOT IN+NULL 全空、COUNT(col) 口径、索引统计。→ 07/17

**7. char/varchar 选择？**
定长 vs 变长；长度按业务反推。→ 16

**8. MySQL 8.0 有哪些新特性？**
窗口函数、CTE/递归、Hash Join、隐藏索引、降序索引、角色、utf8mb4 默认。→ 01

## B. 索引与查询（9-16）

**9. B+ 树为什么不用哈希/B 树/红黑树？⭐**
树高与 IO、叶子链表范围查询、3 层 2000 万行估算。→ 21

**10. 什么是回表、覆盖索引、索引下推？⭐**
回表=二级索引拿主键再查聚簇；覆盖索引免回表（Using index）；ICP=把条件下推引擎在索引层过滤。→ 21/23

**11. 最左前缀原则？联合索引怎么设计？⭐**
字典序；等值在前范围在后排序列收尾；按查询清单设计。→ 22

**12. 索引失效的场景？⭐**
函数包裹、隐式转换（字符串列 vs 数字）、左模糊、OR 非索引列、最左破坏。注意 IS NULL 可走索引。→ 24

**13. EXPLAIN 里 type 等级和关键 Extra？⭐**
system>const>eq_ref>ref>range>index>ALL；Using index/temporary/filesort。→ 23

**14. 深分页怎么优化？⭐**
游标分页 / 延迟关联；LIMIT offset 为什么慢（扫描 offset+size 行）。→ 30

**15. IN 和 EXISTS 谁快？**
8.0 优化器半连接基本自动；NOT IN 遇 NULL 返回空集是真正的考点。→ 10

**16. 窗口函数解决什么问题？**
组内 Top-N（ROW_NUMBER）、排名、环比（LAG）、累计。→ 12

## C. 事务与锁（17-24）

**17. ACID 分别靠什么实现？⭐**
undo 回滚、redo 持久、锁+MVCC 隔离、约束+应用一致性。→ 25/33

**18. 四种隔离级别解决什么问题？默认哪个？⭐**
RU/RC/RR/S 对脏读、不可重复读、幻读；默认 RR。→ 25

**19. MVCC 原理？ReadView 规则？⭐⭐**
隐藏列+undo 版本链+ReadView 四元组；RC 每次新 ReadView、RR 首次生成复用。→ 26

**20. RR 下幻读完全消除吗？⭐**
快照读靠 MVCC 消除；当前读靠临键锁；混合场景仍可见。→ 28

**21. 行锁/间隙锁/临键锁什么时候加？⭐**
唯一键等值命中→Record；未命中/范围→Gap/Next-Key；RC 无 Gap。行锁加在索引上。→ 27

**22. 死锁怎么排查和预防？⭐**
SHOW ENGINE INNODB STATUS；统一加锁顺序、事务短、索引缩小锁范围、应用重试 1213。→ 27

**23. binlog 与 redo log 区别？两阶段提交？⭐⭐**
层次、物理/逻辑、循环写/追加写；2PC 保证崩溃恢复后主从一致。→ 33

**24. 长事务有什么危害？**
undo 膨胀、锁持有、主从延迟、MDL 阻塞 DDL。→ 25/27

## D. 优化与运维（25-30）

**25. 慢 SQL 排查流程？⭐**
慢日志 → pt-query-digest → EXPLAIN ANALYZE → 改写/索引 → 验证。→ 29

**26. 线上 CPU 100% 怎么处理？**
SHOW PROCESSLIST 找 SQL、kill、慢日志定位、EXPLAIN、限流降级。→ 29/30

**27. 主从延迟怎么解决？⭐**
成因（大事务/单线程回放）→ 并行复制、拆事务、读写分离的写后读策略。→ 35

**28. 为什么互联网公司不用外键？⭐**
锁传递、分库分表不支持、数据清理受阻；应用层保证+对账。→ 17

**29. 分库分表怎么选拆分键？带来什么问题？⭐**
80% 查询路由原则；全局 ID、跨片 JOIN/分页、分布式事务、异构索引。→ 32

**30. 大表加字段怎么做？⭐**
8.0 INSTANT 算法；大表 pt-osc/gh-ost；注意 MDL 与长事务互相阻塞。→ 05/27
