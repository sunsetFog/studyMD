# 25 · Set 实现详解

## 1. 三种核心 Set

| 实现 | 底层 | 顺序 | 复杂度 | null |
|---|---|---|---|---|
| `HashSet` | HashMap | 无序 | O(1) | 允许 1 个 |
| `LinkedHashSet` | LinkedHashMap | 插入序 | O(1) | 允许 1 个 |
| `TreeSet` | TreeMap（红黑树） | 排序 | O(log n) | 不允许（自然序） |

```java
Set<String> hash = new HashSet<>();
Set<String> linked = new LinkedHashSet<>();
Set<String> tree = new TreeSet<>();
```

## 2. HashSet 原理

```java
public class HashSet<E> implements Set<E> {
    private transient HashMap<E, Object> map;
    private static final Object PRESENT = new Object();

    public boolean add(E e) { return map.put(e, PRESENT) == null; }
    public boolean contains(Object o) { return map.containsKey(o); }
    public boolean remove(Object o) { return map.remove(o) == PRESENT; }
}
```

> **HashSet 就是一个 value 固定为 `PRESENT` 的 HashMap**。所有 HashMap 的规则（equals/hashCode、容量、树化）都适用。

## 3. 去重原理

```java
Set<User> set = new HashSet<>();
set.add(new User(1L, "Tom"));
set.add(new User(1L, "Tom"));     // 只有重写 equals/hashCode 才会去重
System.out.println(set.size());   // 2（未重写）
```

判断流程：

1. 计算 `hashCode` → 定位桶。
2. 桶内逐个比较：`hash` 相同 && (`==` 或 `equals`)。
3. 都不同 → 插入；相同 → 覆盖（Set 中即不加入）。

**必须同时重写 equals 与 hashCode**，否则：

- 只重写 equals：hash 不同 → 落到不同桶 → 无法去重。
- 只重写 hashCode：hash 同但 equals 返回 false → 仍视为不同。

```java
public record User(Long id, String name) { }   // record 自动生成，天然可去重
```

## 4. LinkedHashSet

```java
Set<String> s = new LinkedHashSet<>();
s.add("c"); s.add("a"); s.add("b");
System.out.println(s);     // [c, a, b] —— 保持插入顺序
```

用途：

- 去重 + 保序（最常见）。
- 实现简单的 FIFO 去重队列。

```java
// 去重同时保持顺序
List<String> distinct = new ArrayList<>(new LinkedHashSet<>(list));
```

## 5. TreeSet

```java
TreeSet<Integer> ts = new TreeSet<>(List.of(5, 1, 3));
System.out.println(ts);            // [1, 3, 5]

ts.first(); ts.last();
ts.floor(4);        // 3（≤4 的最大）
ts.ceiling(4);      // 5（≥4 的最小）
ts.higher(4);       // 5（>4 的最小）
ts.lower(4);        // 3（<4 的最大）
ts.headSet(3);      // [1]
ts.tailSet(3);      // [3, 5]
ts.subSet(1, 5);    // [1, 3]
ts.pollFirst();     // 弹出最小
ts.descendingSet();
```

### 排序依据

- 元素实现 `Comparable`（自然序），或
- 构造时传 `Comparator`。

```java
TreeSet<String> byLen = new TreeSet<>(Comparator.comparingInt(String::length).thenComparing(Comparator.naturalOrder()));
```

### 去重依据

TreeSet 用 `compareTo`（或 Comparator）判断相等，**不是 equals**：

```java
TreeSet<BigDecimal> ts = new TreeSet<>();
ts.add(new BigDecimal("1.0"));
ts.add(new BigDecimal("1.00"));
System.out.println(ts.size());   // 1（compareTo == 0）
```

## 6. EnumSet

```java
EnumSet<Status> set = EnumSet.of(Status.CREATED, Status.PAID);
EnumSet<Status> all = EnumSet.allOf(Status.class);
EnumSet<Status> none = EnumSet.noneOf(Status.class);
EnumSet<Status> range = EnumSet.range(Status.CREATED, Status.SHIPPED);

set.contains(Status.PAID);      // O(1)
set.add(Status.DONE);
set.remove(Status.CREATED);
```

原理：内部用 `long`（≤64 个枚举）或 `long[]` 位向量，**每个元素 1 bit**。

性能：比 HashSet 快数倍，内存极小。**枚举集合一律用 EnumSet**。

注意：

- 不允许 null。
- 非线程安全。
- 迭代时修改抛 CME。

## 7. CopyOnWriteArraySet

```java
Set<String> set = new CopyOnWriteArraySet<>();
```

内部是 `CopyOnWriteArrayList`，`add` 时遍历检查重复 → **O(n)**。

适用：读多写极少、元素少（监听器集合）。元素多时性能极差。

## 8. ConcurrentSkipListMap/Set

```java
ConcurrentSkipListSet<Integer> set = new ConcurrentSkipListSet<>();
```

- 基于跳表，O(log n)。
- 线程安全、支持排序、支持范围查询。
- 并发场景需要「有序 Set」时的唯一选择（没有 ConcurrentTreeSet）。

## 9. 集合运算

```java
Set<Integer> a = new HashSet<>(Set.of(1, 2, 3));
Set<Integer> b = new HashSet<>(Set.of(2, 3, 4));

// 并集
Set<Integer> union = new HashSet<>(a); union.addAll(b);          // [1,2,3,4]

// 交集
Set<Integer> inter = new HashSet<>(a); inter.retainAll(b);       // [2,3]

// 差集 a - b
Set<Integer> diff = new HashSet<>(a); diff.removeAll(b);         // [1]

// 对称差
Set<Integer> sym = new HashSet<>(a); sym.addAll(b); sym.removeAll(new HashSet<>(a){{ retainAll(b); }});
// 或用 Stream
```

Java 9+ 不可变集合：

```java
Set<Integer> s = Set.of(1, 2, 3);
```

## 10. 常见用途

```java
// 1. 去重
List<String> unique = new ArrayList<>(new HashSet<>(list));

// 2. 存在性判断（替代 List.contains）
Set<Long> ids = orders.stream().map(Order::getId).collect(Collectors.toSet());
if (ids.contains(id)) { }

// 3. 白名单/黑名单
private static final Set<String> ALLOWED = Set.of("jpg", "png", "gif");

// 4. 已访问节点（图遍历）
Set<Node> visited = new HashSet<>();

// 5. 标签集合（EnumSet）
EnumSet<Permission> perms = EnumSet.of(Permission.READ, Permission.WRITE);
```

## 11. 性能对比

| 操作 | HashSet | LinkedHashSet | TreeSet | EnumSet |
|---|---|---|---|---|
| add | O(1) | O(1) | O(log n) | O(1) 位运算 |
| contains | O(1) | O(1) | O(log n) | O(1) |
| 内存/元素 | 中等 | 较高（链表指针） | 高（树节点） | 1 bit |
| 顺序 | 无 | 插入序 | 排序 | 枚举声明序 |

## 12. 常见坑

1. 自定义对象未重写 `equals/hashCode` → 去重失效。
2. 放入 HashSet 后修改参与 hash 的字段 → 无法删除/查找。
3. `TreeSet` 添加 `null`（自然序）→ NPE。
4. `TreeSet` 用 `compareTo` 判等，与 `equals` 不一致时行为反直觉。
5. `Set.of` 有重复元素 → `IllegalArgumentException`（运行时，编译期查不出字面量重复时）。
6. `Set.of` 不允许 null。
7. 遍历 Set 期望顺序 → 必须用 LinkedHashSet 或 TreeSet。
8. 并发环境用 HashSet → 用 `ConcurrentHashMap.newKeySet()`。

```java
// 并发 Set 的正确写法
Set<String> concurrentSet = ConcurrentHashMap.newKeySet();
```

## 13. 速查

```java
// 保序去重
new LinkedHashSet<>(list)

// 排序去重
new TreeSet<>(list)

// 不可变
Set.copyOf(set)
Set.of(...)

// 并发
ConcurrentHashMap.newKeySet()

// 枚举
EnumSet.allOf(Type.class)

// 转 List
new ArrayList<>(set)
```
