# 14 · 枚举（enum）

## 1. 本质

```java
public enum Status { CREATED, PAID, SHIPPED, DONE }
```

编译后等价于：

```java
public final class Status extends Enum<Status> {
    public static final Status CREATED = new Status("CREATED", 0);
    public static final Status PAID = new Status("PAID", 1);
    // ...
    private static final Status[] $VALUES = { CREATED, PAID, SHIPPED, DONE };
    public static Status[] values() { return $VALUES.clone(); }
    public static Status valueOf(String name) { return Enum.valueOf(Status.class, name); }
}
```

要点：

- 继承 `java.lang.Enum`，因此**不能再继承其他类**，但可以实现接口。
- 隐式 `final`（除非有抽象方法时每个常量是匿名子类）。
- 构造器隐式 `private`。
- 天然单例、线程安全、可序列化（序列化按名字，不会创建新实例）。

## 2. 带字段与方法的枚举

```java
public enum OrderStatus {
    CREATED(10, "已创建"),
    PAID(20, "已支付"),
    SHIPPED(30, "已发货"),
    DONE(40, "已完成"),
    CANCELED(90, "已取消");

    private final int code;
    private final String label;

    OrderStatus(int code, String label) {   // 隐式 private
        this.code = code;
        this.label = label;
    }

    public int getCode() { return code; }
    public String getLabel() { return label; }

    public static OrderStatus of(int code) {
        for (OrderStatus s : values()) {
            if (s.code == code) return s;
        }
        throw new IllegalArgumentException("unknown code: " + code);
    }

    // 优化：用静态 Map 缓存，O(1)
    private static final Map<Integer, OrderStatus> BY_CODE =
        Arrays.stream(values()).collect(Collectors.toUnmodifiableMap(OrderStatus::getCode, s -> s));
}
```

## 3. 枚举 + 抽象方法（状态机）

```java
public enum Operation {
    PLUS("+") {
        @Override public int apply(int a, int b) { return a + b; }
    },
    MINUS("-") {
        @Override public int apply(int a, int b) { return a - b; }
    },
    TIMES("*") {
        @Override public int apply(int a, int b) { return a * b; }
    };

    private final String symbol;
    Operation(String symbol) { this.symbol = symbol; }
    public String symbol() { return symbol; }
    public abstract int apply(int a, int b);
}
```

这比 `switch` 更符合开闭原则：新增运算符只加一个常量，不改已有代码。

## 4. 枚举实现接口

```java
public interface Describable {
    String describe();
}

public enum Priority implements Describable {
    LOW { public String describe() { return "低"; } },
    HIGH { public String describe() { return "高"; } };
}
```

## 5. 常用方法

```java
Status s = Status.PAID;

s.name();                 // "PAID"（不要用 toString 做持久化）
s.ordinal();              // 1（声明顺序，禁止持久化）
s.toString();             // 默认同 name，可重写
Status.valueOf("PAID");   // 按名字查找，找不到抛 IllegalArgumentException
Status.values();          // 返回副本数组，每次调用都创建数组！

// 比较：直接用 ==（枚举实例唯一）
if (s == Status.PAID) { }

// 排序：按 ordinal
EnumSet.allOf(Status.class);
```

**性能提示**：`values()` 每次 clone 数组，循环内避免反复调用。

```java
// 差
for (int i = 0; i < Status.values().length; i++)
// 好
Status[] all = Status.values();
```

## 6. EnumSet / EnumMap

```java
// EnumSet：位向量实现，极高效
EnumSet<Status> active = EnumSet.of(Status.CREATED, Status.PAID);
EnumSet<Status> all = EnumSet.allOf(Status.class);
EnumSet<Status> none = EnumSet.noneOf(Status.class);
EnumSet<Status> range = EnumSet.range(Status.CREATED, Status.SHIPPED);
active.contains(Status.PAID);       // O(1)

// EnumMap：数组实现，比 HashMap 快且内存小
EnumMap<Status, String> map = new EnumMap<>(Status.class);
map.put(Status.PAID, "已支付");
```

> 枚举做 key 时**优先用 EnumMap**，不要用 HashMap。

## 7. 枚举单例

```java
public enum Singleton {
    INSTANCE;

    private final AtomicInteger counter = new AtomicInteger();

    public int next() { return counter.incrementAndGet(); }
}
```

优点：

- 线程安全由 JVM 类初始化保证。
- 防反射攻击（`Constructor.newInstance` 对 enum 抛异常）。
- 防反序列化创建新实例。

《Effective Java》推荐的单例写法。

## 8. 枚举 vs 常量类

| 维度 | `static final int` | enum |
|---|---|---|
| 类型安全 | 差（任意 int 都能传） | 强 |
| 可读性 | 日志只有数字 | 有名字 |
| 遍历 | 需手写 | `values()` |
| 可扩展 | 无 | 可带字段/方法 |
| 序列化 | 数值 | 名字，稳定 |
| 性能 | 略高（int） | 接近，JIT 优化后几乎无差 |

结论：**业务常量一律用 enum**，只有极底层性能敏感代码用 int 常量。

## 9. 持久化注意事项

- 数据库存 `name()` 或自定义 `code`，**不要存 `ordinal()`**（顺序一变全错）。
- JSON 序列化默认用 `name()`；需要输出 code 时用 `@JsonValue`。
- 前端传值用 code 时，加 `@JsonCreator` 反序列化。

```java
public enum Status {
    CREATED(10);

    @JsonValue public int getCode() { return code; }

    @JsonCreator
    public static Status of(int code) { ... }
}
```

## 10. 常见坑

1. `values()` 在循环条件中反复调用（每次克隆数组）。
2. 用 `ordinal()` 做数据库字段或协议值。
3. 用 `equals` 比较枚举（可以用，但 `==` 更安全且防 NPE）。
4. 枚举中静态初始化块引用常量顺序问题：

```java
enum Bad {
    A, B;
    static final Map<String, Bad> M = new HashMap<>();
    static {
        // 静态块在常量构造之后执行，OK
    }
}
```

5. 枚举常量构造器中不能访问静态字段（静态初始化未完成）：

```java
enum Bad2 {
    A;
    static int x = 1;
    Bad2() {
        // System.out.println(x);  // 编译错误：illegal reference to static field
    }
}
```

6. `switch` 中枚举为 null 会 NPE（switch 表达式需 `case null`）。

## 11. 实战：状态机

```java
public enum OrderState {
    CREATED {
        @Override public OrderState pay() { return PAID; }
        @Override public OrderState cancel() { return CANCELED; }
    },
    PAID {
        @Override public OrderState ship() { return SHIPPED; }
        @Override public OrderState refund() { return CANCELED; }
    },
    SHIPPED {
        @Override public OrderState confirm() { return DONE; }
    },
    DONE, CANCELED;

    public OrderState pay() { throw new IllegalStateException(name() + " 不支持支付"); }
    public OrderState ship() { throw new IllegalStateException(name() + " 不支持发货"); }
    public OrderState confirm() { throw new IllegalStateException(name() + " 不支持确认"); }
    public OrderState cancel() { throw new IllegalStateException(name() + " 不支持取消"); }
    public OrderState refund() { throw new IllegalStateException(name() + " 不支持退款"); }
}
```

非法流转在编译期/运行期都有明确保护，比散落的 if-else 可靠得多。
