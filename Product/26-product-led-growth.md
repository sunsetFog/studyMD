# 26 · PLG：让产品自己卖自己

## 1. 什么是 PLG（Product-Led Growth）

> 增长主要由**产品体验**驱动，而非销售/市场驱动。用户自助注册、自助体验、自助付费。

| 模式 | 驱动力 | 获客方式 | 典型 |
|---|---|---|---|
| SLG（销售驱动） | 销售团队 | 线索→销售→合同 | Oracle、SAP |
| MLG（市场驱动） | 市场投放 | 广告→落地页→销售 | 传统 B2B |
| **PLG** | 产品本身 | 试用→自助转化→口碑 | Slack、Notion、Figma |
| PLG+Sales | 产品获客 + 销售放大 | 自助起步 → 大单由销售接手 | ★ 主流 SaaS 现状 |

## 2. PLG 成立的三个前提

```
① 用户能自助上手（无需培训/实施）
② 产品能在短时间内交付价值（Time-to-Value 短）
③ 有价值可免费体验（免费版/试用期）
```

不满足（如需要复杂实施、需要企业数据对接）则不适合纯 PLG，可用「PLG + 销售辅助」。

## 3. PLG 的核心飞轮

```
用户注册 → 快速体验价值（Aha Moment）→ 深度使用
   → 协作/分享（带来新用户）→ 产生付费需求 → 自助升级
      → 团队扩散 → 企业买单
```

关键杠杆：

| 杠杆 | 说明 |
|---|---|
| **TTV（Time to Value）** | 从注册到感受到价值的时长，越短越好（目标 < 5 分钟） |
| **病毒循环** | 产品的协作/分享属性带来新用户 |
| **付费墙位置** | 在用户感受到价值之后拦截 |
| **扩张收入** | 从个人 → 团队 → 企业（席位与功能扩张） |

## 4. 免费版（Free）vs 免费试用（Trial）

| 类型 | 特点 | 适用 |
|---|---|---|
| 永久免费版（Freemium） | 无时间压力，用户慢慢来，可长期积累 | ★ 需要网络效应/长期养成的产品 |
| 限时试用（Free Trial） | 有紧迫感，转化率高，但流失也快 | 价值明确、上手快的产品 |
| 反向试用（Reverse Trial） | 先给高级功能，到期降级 | 高级功能已成为习惯后更易转化 |
| 免费+用量限制 | 免费用但有限额 | ★ AI 产品主流（成本约束） |

**付费墙设计原则**：

```
① 让用户在付费前就获得过价值（用过才知道值）
② 在用户「想要更多」的时候拦截，而不是一进门就拦
③ 拦的是「进阶需求」，不是「核心体验」
④ 提供清晰的升级理由（具体得到什么）
⑤ 不要阻断用户已有数据的访问（会引发反感）
```

## 5. PLG 的关键指标

| 指标 | 说明 |
|---|---|
| 注册 → 激活转化率 | 完成核心行为的比例 |
| TTV | 首次价值时间 |
| 自助转化率 | 免费 → 付费的比例（SaaS 通常 2-5%，优秀 5-10%） |
| 病毒系数 K | 每用户带来的新用户 |
| 扩张收入 / NDR | 净收入留存，健康 > 100% |
| 销售介入率 | 自助用户中有多少被转化为大客户 |

## 6. 产品内的增长机制设计

| 机制 | 说明 | 注意 |
|---|---|---|
| 协作邀请 | 用产品必须拉人 | 天然病毒 |
| 分享作品 | 结果带品牌露出 | ★ AI 生成内容天然适合 |
| 模板/社区 | UGC 降低新用户门槛 | 需要冷启动运营 |
| 账号体系升级 | 个人 → 团队（管理员出现） | 转化关键点 |
| 用量/额度提醒 | 接近上限时提示升级 | 时机要准（正在使用时） |
| 成就/连续使用 | 习惯养成 | 慎用焦虑营销 |

## 7. PLG 与销售结合（PQL）

```
PQL（Product Qualified Lead）：通过产品行为识别出的高意向线索
  信号：用量接近上限、邀请了多个成员、使用了高级功能、多次访问定价页
```

流程：产品识别 PQL → 销售主动触达 → 转化大单。比传统线索质量高得多。

## 8. ★ AI 产品的 PLG 要点

| 要点 | 说明 |
|---|---|
| **免费额度要能出效果** | 免费用户必须能成功产出至少一次结果，否则不会转化 |
| **成本风控并行** | 免费额度 = 成本，要有防刷（邮箱/手机号验证、异常检测） |
| **TTV 极短是优势** | AI 产品的价值交付可以很快（输入即得结果），这是天然 PLG 优势 |
| **结果分享即传播** | 生成的内容带水印/链接分享，是低成本获客 |
| **用量墙优于功能墙** | 让用户用全部功能，但限制次数（体验完整 + 成本可控） |
| **「作品」沉淀** | 历史产出是留存与迁移成本的核心 |
| **PQL 信号** | 高频使用、额度用尽、团队协作、API 调用需求 |
| **模型能力即卖点** | 免费用户也能感受到「效果好」，口碑传播快 |

## 9. 常见坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 免费版太弱 | 用户感受不到价值，不转化 | 免费版要能完成核心价值 |
| 免费版太强 | 没人付费 | 限制的是「规模/频次/协作」而非核心能力 |
| 付费墙太早 | 注册就要付款 | 先给价值再拦截 |
| 付费墙太晚 | 用户白嫖成习惯 | 到达价值点后及时引导 |
| 忽略 TTV | 注册后一堆设置 | 减少注册摩擦，快速给结果 |
| 没有病毒机制 | 只能靠买量 | 设计协作/分享路径 |
| AI 免费额度被刷 | 成本爆表 | 验证 + 限额 + 异常检测 |
| 只做自助不做服务 | 大客户流失 | PLG + 高触达销售组合 |

## 10. Checklist

- [ ] TTV < 5 分钟，可量化监控
- [ ] 免费版能完成核心价值体验
- [ ] 付费墙在价值点之后，限制的是规模而非核心能力
- [ ] 设计了至少一个自然的病毒/协作路径
- [ ] 有 PQL 识别规则与销售衔接流程
- [ ] AI 产品：免费额度既能出效果又有成本风控
- [ ] 监控自助转化率、NDR、K 因子
