# 08 · 产品定位：你到底是什么、为谁、凭什么

## 1. 定位的本质

> 定位不是你对产品做什么，而是**你在用户心智中占据什么位置**。

用户心智容量有限（一个品类通常只记得 2-3 个品牌）。定位的目标是：当用户遇到某个 Job 时，**第一个想到你**。

## 2. 定位三要素

```
① 目标用户（为谁）：具体到能想象出一个人
② 价值主张（提供什么价值）：解决什么问题、带来什么结果
③ 差异点（凭什么是你）：你有什么别人没有/做不到的
```

### 定位陈述模板

```
对于【目标用户】，
【产品名】是一个【品类】，
它能【核心价值/关键利益】，
不同于【主要竞品】，
我们【关键差异点/理由】。

例：
对于【每天要出多条商品文案的中小电商运营】，
「妙笔」是一个【AI 商品文案工具】，
它能【3 分钟产出一批符合平台规范的文案】，
不同于【通用 ChatGPT】，
我们【内置各平台违禁词库与爆款模板，且支持批量一键生成】。
```

## 3. 价值主张画布（Value Proposition Canvas）

```
【用户画像】              【价值主张】
任务（Jobs）        ←→    产品与服务
痛点（Pains）       ←→    痛点缓解剂
收益（Gains）       ←→    收益创造器
```

**匹配原则**：每个痛点都要有对应的缓解方案；没有痛点支撑的功能是多余功能。

## 4. 差异化的四种来源

| 类型 | 说明 | 例子 | 可复制性 |
|---|---|---|---|
| 技术/能力 | 别人做不到的效果 | 独家模型、专有算法 | 中（★ 模型容易被追平） |
| 数据/领域 | 专有数据或行业 know-how | 医疗知识库、平台违禁词库 | 高（较难复制） |
| 工作流/集成 | 深度嵌入用户现有流程 | 与飞书/Shopify 深度集成 | 高 |
| 体验/品牌 | 更快更顺手、用户信任 | 极简交互、行业口碑 | 中 |

> ★ 对 AI 应用来说：**模型能力不是护城河**（大家调的是同一批 API）。真正可持续的是 ② 数据/领域 和 ③ 工作流集成。

## 5. 品类选择：做「更好的 X」还是「新品类的第一」

| 策略 | 优点 | 风险 |
|---|---|---|
| 更好的 X（在成熟品类里做得更好） | 需求已被验证，用户懂 | 要打过 incumbents，需要明显优势 |
| 新品类第一 | 定义规则，心智独占 | 需要教育市场，可能没需求 |

**多数 AI 创业的正确选择**：在成熟 Job 上做「10 倍体验提升」，用旧品类语言描述，用新技术实现。

> 反例：「我们是下一代 AI Agent 原生生产力平台」——用户不知道你在说什么。
> 正例：「自动生成周报的工具」——用户秒懂。

## 6. 定位的验证方法

| 方法 | 做法 | 判定 |
|---|---|---|
| 电梯陈述测试 | 30 秒说完，对方能复述 | 复述准确度 |
| 落地页测试 | 不同定位做多个落地页 | 转化率差异 |
| 搜索关键词 | 看用户搜什么词找到你 | 是否与你的定位词一致 |
| 用户转述 | 让用户向朋友介绍你的产品 | 他用的词就是真实心智定位 |
| 留存分层 | 哪类用户留存最高 | 他们就是你的真实目标用户 |

## 7. 定位的常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 贪大 | 「服务所有需要写作的人」 | 收窄到能具体想象的人 |
| 只讲功能 | 「基于大模型的一站式平台」 | 讲用户结果与差异点 |
| 没有差异化 | 「智能、高效、便捷」 | 必须能说清和对手的不同 |
| 定位漂移 | 每个新客户都改一次定位 | 定位至少稳定 6-12 个月 |
| 自嗨式定位 | 「重新定义 XX」 | 用户能懂才算数 |

## 8. ★ AI 产品的定位要点

| 要点 | 说明 |
|---|---|
| **别用模型名定位** | 「基于 GPT-4 的 XX」明天就过时，定位要讲结果 |
| **明确人机分工** | 你做的是「AI 全自动」还是「AI 辅助人」——心智差异巨大 |
| **可验证性作为卖点** | 在容错低的领域，「每条结果可溯源」比「更聪明」更值钱 |
| **不承诺 100%** | 定位里不要暗示绝对正确，会引发信任崩塌 |
| **能力边界写清楚** | 明确不做什么是专业表现（如「不做医疗诊断建议」） |
| **跟随模型能力演进** | 定位要留弹性：模型进步后你的价值主张是否还成立 |

## 9. 常见坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 定位写在 PPT 里，产品没体现 | 说是极简工具，界面一堆设置 | 定位要落到功能取舍 |
| 目标用户太宽 | 「中小企业」 | 缩到「20 人以下的电商团队」 |
| 差异点不可持续 | 「我们模型更先进」 | 换成数据或工作流优势 |
| 频繁改定位 | 半年改三次 | 改定位等于重启，慎之又慎 |
| 不考虑已有心智 | 用户已经把你归到某类 | 借势比硬掰容易 |

## 10. Checklist

- [ ] 能用一句话定位陈述说清为谁、是什么、凭什么
- [ ] 价值主张画布四象限有对应关系
- [ ] 差异化来自数据/工作流而非仅模型能力
- [ ] 目标用户窄到能想象出一个具体的人
- [ ] 做过用户转述测试，用户能用自己的话复述
