# 06 · 竞品分析：看清战场位置

## 1. 竞品分析的三个目的

```
① 找机会：市场上哪里还没被满足（空白点）
② 定标准：这个领域的「及格线」和「优秀线」在哪
③ 避坑：别人踩过的坑别再踩（尤其是 AI 产品的体验坑）
```

不是为了抄功能。**看竞品的功能列表是最低级的竞品分析**。

## 2. 竞品分层

| 层级 | 定义 | 例子（AI 写作工具） |
|---|---|---|
| 直接竞品 | 同需求、同用户、同形态 | 其他 AI 写作 SaaS |
| 间接竞品 | 同需求、不同形态 | 外包写手、模板网站 |
| 替代方案 | 不同需求但抢同一时间/预算 | 短视频、Excel |
| 潜在竞品 | 现在不是，将来可能是 | 大模型厂商自带能力 |

> **用户现有的解决方式才是你最大的竞品**。AI 写作工具真正的对手常常是「自己硬写」和「用 ChatGPT 免费版」。

## 3. 分析方法一：功能对比矩阵

```markdown
| 功能 | 我们 | 竞品A | 竞品B | 说明 |
|---|---|---|---|---|
| 长文生成 | ✓ | ✓ | ✓ | 及格线 |
| 品牌语调定制 | 规划中 | ✓ | ✗ | A 的差异化 |
| 团队协作 | ✓ | ✗ | ✓ | 我们的优势 |
| API | ✗ | ✓ | ✗ | 要考虑开发者生态 |
```

注意：**功能有无不等于体验好坏**，矩阵只能说明覆盖范围，不能说明质量。

## 4. 分析方法二：用户体验要素拆解（5 层）

```
表现层：视觉、UI 细节
框架层：布局、导航、信息架构
结构层：流程、交互路径
范围层：功能规格、内容需求
战略层：用户目标 + 商业目标 ← 最关键，决定了上面四层为何这样
```

**分析竞品必须先还原它的战略层**：它为谁服务？靠什么赚钱？这解释了它为什么做这些取舍。

## 5. 分析方法三：用户旅程对比

选同一任务（如「写一篇公众号文章」），走完竞品全流程，记录：

| 阶段 | 步骤数 | 耗时 | 卡点 | 惊喜点 |
|---|---|---|---|---|
| 上手 | 3 步 | 40s | 要先选 5 个参数 | 有示例引导 |
| 生成 | 1 步 | 12s | 不能中断 | 流式输出 |
| 修改 | 2 步 | — | 只能整段重写 | 支持选中局部改写 |

**步骤数 × 耗时** 是硬指标，比主观评价可靠。

## 6. 分析方法四：商业模式与数据侧写

| 维度 | 怎么查 |
|---|---|
| 定价与套餐 | 官网 pricing 页，注意阶梯与限制项 |
| 流量规模 | SimilarWeb、Google Trends、SEO 关键词 |
| 用户口碑 | 应用商店评论、小红书/知乎/Reddit、G2 |
| 团队与融资 | 融资新闻、招聘 JD（招聘需求暴露战略方向） |
| 迭代速度 | 更新日志、版本历史频率 |
| 技术栈 | 页面源码、API 请求、模型指纹（★ AI 产品可探测用了哪家模型） |

## 7. 输出物：竞品分析报告模板

```markdown
# XX 竞品分析

## 一、结论先行
- 机会点：xxx
- 我们应该：xxx（差异化切入 / 跟随 / 放弃这个市场）

## 二、市场格局
- 玩家分层图（头部 / 腰部 / 长尾）
- 各家的定位与用户群

## 三、竞品深度拆解（选 2-3 个）
- 战略层：为谁、解决什么、怎么赚钱
- 体验层：主流程步骤数、耗时、卡点
- 能力层：核心能力实测（★ AI 产品要做同题测试）

## 四、差异化机会
| 机会点 | 可行性 | 我们的优势 | 风险 |

## 五、建议与下一步
- 立刻可以学的 3 件事
- 要避开的 2 个坑
- 需要验证的假设
```

## 8. ★ AI 产品的竞品分析特殊点

| 特殊点 | 做法 |
|---|---|
| **同题实测** | 用同一组 prompt 跑竞品，对比输出质量（建 benchmark 集） |
| **模型识别** | 从回答风格/延迟/价格推测底层模型，判断其成本结构 |
| **能力同质化** | 模型能力趋同，**护城河在数据、工作流、集成、品牌** |
| **迭代速度极快** | 竞品分析的有效期约 1 个月，需持续跟踪 |
| **看免费替代品** | ChatGPT/Claude 原生就是最大竞品，要想清楚为什么用户用你而不用它们 |
| **Prompt/知识库** | 有些产品公开了 prompt，是最有价值的学习材料 |

## 9. 常见坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 只抄功能 | 「竞品有我们也要有」 | 先问竞品的定位和战略是否与你一致 |
| 只看头部 | 忽略垂直小玩家 | 垂直玩家常常才是你的真对手 |
| 静态分析 | 一年前的报告还在用 | 建立持续跟踪机制（订阅更新日志） |
| 不带结论 | 30 页报告没有建议 | 结论前置，报告只服务于决策 |
| 忽略替代方案 | 只盯着同类 App | 研究用户「现在怎么解决」 |
| 主观评价 | 「体验比我们好」 | 用步骤数、耗时、完成率说话 |

## 10. Checklist

- [ ] 明确了直接/间接/替代/潜在四层竞品
- [ ] 还原了竞品的战略层（为谁、怎么赚钱）
- [ ] 做过同任务流程的量化对比（步骤数、耗时）
- [ ] AI 产品做过同题输出质量实测
- [ ] 报告结论前置，给出了明确的行动建议
